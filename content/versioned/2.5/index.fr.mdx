Nucleus est la couche desktop de production pour les applications Compose Multiplatform écrites en Kotlin.
Compose dessine l'UI ; Nucleus ajoute les décorations de fenêtre natives, l'intégration au système
d'exploitation, la signature de code, les installateurs et les pipelines store. Vous configurez tout
le build via un seul DSL Gradle, et le runtime s'exécute soit comme une image native GraalVM, soit sur
la JVM.

Si vous shippez déjà Android ou KMP, Nucleus est la façon dont la même équipe shippe le desktop —
sans seconde stack.

## Fonctionnalités

- **Un seul langage pour toutes les plateformes.** Partagez votre code Kotlin avec vos apps Android, iOS et web, avec Compose UI par-dessus.
- **Fenêtrage natif (Tao).** Wayland, multi-touch, stylet, [scaffold de fenêtre](/docs/tao/window-scaffold), [TextureView](/docs/tao/texture-view) pour les frames GPU externes, et [contexte de rendu GPU](/docs/tao/gpu-render-context) pour les renderers in-process.
- **Deux runtimes, un seul DSL.** Exécution en image native GraalVM, ou sur la JVM avec un cache AOT (JDK 25+).
- **Plus de 40 modules d'intégration OS.** Notifications, system tray, menus dock, dark mode, hotkeys globaux et barre des tâches, chacun ajouté comme dépendance optionnelle.
- **18 formats d'installateur.** DMG, PKG, MSI, AppX, DEB, RPM, AppImage, Snap et Flatpak entre autres, avec signature de code, notarisation et [auto-update différentiel](/docs/packaging/auto-update#téléchargements-différentiels).
- **Design systems natifs.** [macOS 26](https://github.com/NucleusFramework/compose-macos-26-ui), [Fluent](https://github.com/NucleusFramework/compose-fluent-ui) et [Yaru](https://github.com/NucleusFramework/yaru-compose-ui) sur Maven Central, plus Jewel et Material dans ce dépôt. Voir [toolkits](/docs/window/toolkits).

Pour construire votre première app, suivez le [quickstart](/docs/start/quickstart).

## Quoi de neuf en 2.5

- **Correction orthographique.** Le moteur de l'OS dans les champs de texte Compose — Hunspell, `NSSpellChecker`, Windows Spell Checking — avec les suggestions dans le menu contextuel. Voir [Correction orthographique](/docs/os/spell-check#vérifier-un-champ-de-texte).
- **Menus contextuels natifs.** Un drapeau remplace le menu Compose par celui de la plateforme : `NSMenu`, Fluent, Adwaita ou Breeze. Voir [Menus contextuels](/docs/window/context-menu#activer-le-menu-natif).
- **Fenêtres overlay.** Drapeaux traversant, arrière-plan permanent et tous-les-bureaux, pour watermarks et widgets de bureau. Voir [Fenêtres overlay](/docs/tao/overlay-windows#construire-un-watermark-traversant).
- **Compose au-dessus des vues natives.** L'emplacement d'overlay de `NativeView` dessine désormais dans la scène de la fenêtre sur les trois plateformes. Voir [Superposer du contenu Compose](/docs/tao/native-views#superposer-du-contenu-compose).
- **Compose 1.12** est requis à partir de cette ligne. Voir [Compatibilité](/docs/start/install#compatibilité).
