Nucleus is the production desktop layer for Compose Multiplatform apps written in Kotlin. Compose draws
the UI; Nucleus adds native window decorations, operating-system integration, code signing, installers,
and store pipelines. You configure the whole build through a single Gradle DSL, and the runtime runs
either as a GraalVM native image or on the JVM.

If you already ship Android or KMP, Nucleus is how the same team ships desktop — without a second stack.

## Features

- **One language across platforms.** Share Kotlin code with your Android, iOS, and web apps, with Compose UI on top.
- **Native windowing (Tao).** Wayland support, multi-touch, pen input, [window scaffold](/docs/tao/window-scaffold), [TextureView](/docs/tao/texture-view) for external GPU frames, and [GPU render context](/docs/tao/gpu-render-context) for in-process renderers.
- **Two runtimes, one DSL.** Run as a GraalVM Native Image, or on the JVM with an AOT cache (JDK 25+).
- **Over 40 OS integration modules.** Notifications, system tray, dock menus, dark mode, global hotkeys, and taskbar integration, each added as an opt-in dependency.
- **18 packaging formats.** DMG, PKG, MSI, AppX, DEB, RPM, AppImage, Snap, and Flatpak among them, with code signing, notarization, and [differential auto-update](/docs/packaging/auto-update#differential-downloads).
- **Native design systems.** [macOS 26](https://github.com/NucleusFramework/compose-macos-26-ui), [Fluent](https://github.com/NucleusFramework/compose-fluent-ui), and [Yaru](https://github.com/NucleusFramework/yaru-compose-ui) on Maven Central, plus Jewel and Material adapters in this repo. See [toolkits](/docs/window/toolkits).

To build your first app, follow the [quickstart](/docs/start/quickstart).

## What's new in 2.5

- **Spell check.** The OS spell engine in Compose text fields — Hunspell, `NSSpellChecker`, Windows Spell Checking — with suggestions in the context menu. See [Spell check](/docs/os/spell-check#check-a-text-field).
- **Native context menus.** One flag swaps the Compose menu for the platform's: `NSMenu`, Fluent, Adwaita, or Breeze. See [Context menus](/docs/window/context-menu#turn-on-the-native-menu).
- **Overlay windows.** Click-through, always-on-bottom, and all-workspaces flags for watermarks and desktop widgets. See [Overlay windows](/docs/tao/overlay-windows#build-a-click-through-watermark).
- **Compose over native views.** The `NativeView` overlay slot now draws in the window's own scene on all three platforms. See [Overlay Compose content](/docs/tao/native-views#overlay-compose-content).
- **Compose 1.12** is required from this line on. See [Compatibility](/docs/start/install#compatibility).
