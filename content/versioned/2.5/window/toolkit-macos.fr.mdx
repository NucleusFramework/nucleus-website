[compose-macos-26-ui](https://github.com/NucleusFramework/compose-macos-26-ui) est un design
system Compose Multiplatform pour le look macOS 26 : composants, tokens de thème, icônes, et
une `MacosDecoratedWindow` desktop sur le backend Tao de Nucleus. Cibles : Android, iOS,
desktop JVM et web (JS/Wasm). Versionné indépendamment de Nucleus (release courante **1.0.0**).

Galerie live : [nucleusframework.github.io/compose-macos-26-ui](https://nucleusframework.github.io/compose-macos-26-ui/).

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
plugins {
    id("dev.nucleusframework")
}

dependencies {
    implementation("dev.nucleusframework:compose-macos-ui:1.0.0")
}
```

`compose-macos-ui` expose déjà `nucleus.nucleus-application` et `nucleus.decorated-window-tao`
en `api` sur la cible JVM.

## Ouvrir une fenêtre décorée

```kotlin
import dev.nucleusframework.application.nucleusApplication
import dev.nucleusframework.macoscompose.theme.MacosTheme
import dev.nucleusframework.macoscompose.window.MacosDecoratedWindow

fun main() = nucleusApplication {
    MacosDecoratedWindow(
        onCloseRequest = ::exitApplication,
        title = "Mail",
    ) {
        MacosTheme(darkTheme = false) {
            App()
        }
    }
}
```

Placez `MacosTheme` **à l'intérieur** du contenu de la fenêtre pour que les surfaces natives
suivent le thème de l'app.

## Fonctionnement

Sur desktop, `MacosDecoratedWindow` enveloppe le `DecoratedWindow` Nucleus (Tao) : contenu
plein cadre, grand rayon de coin via `NSToolbar` invisible, feux de circulation recentrés, et
matériaux natifs.
