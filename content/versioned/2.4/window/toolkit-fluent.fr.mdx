[compose-fluent-ui](https://github.com/NucleusFramework/compose-fluent-ui) est un fork maintenu
de la bibliothèque Fluent Design pour Compose Multiplatform (desktop, Android, iOS, web). Le
module `decorated-window-fluent` ajoute une fenêtre décorée côté client Nucleus/Tao avec Mica /
Acrylic natifs sous Windows. Versionné indépendamment de Nucleus (release courante **1.0.0**).

Galerie live : [nucleusframework.github.io/compose-fluent-ui](https://nucleusframework.github.io/compose-fluent-ui/).

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework.composefluent:fluent:1.0.0")
    implementation("dev.nucleusframework.composefluent:fluent-icons-extended:1.0.0") // optionnel
    implementation("dev.nucleusframework.composefluent:decorated-window-fluent:1.0.0")
}
```

## Ouvrir une fenêtre Fluent

```kotlin
import dev.nucleusframework.application.nucleusApplication
import dev.nucleusframework.window.fluent.FluentDecoratedWindow
import dev.nucleusframework.window.fluent.FluentTitleBar
import io.github.composefluent.FluentTheme

fun main() = nucleusApplication {
    FluentDecoratedWindow(onCloseRequest = ::exitApplication, title = "Paramètres") {
        FluentTheme {
            FluentTitleBar { /* … */ }
            App()
        }
    }
}
```

Les widgets sont sous `io.github.composefluent.component` ; le thème s'ouvre avec `FluentTheme()`.

## Fonctionnement

`decorated-window-fluent` mappe les couleurs Fluent sur le chrome Nucleus et branche
`WindowsBackdrop` pour le vrai Mica / Acrylic DWM sous Windows.
