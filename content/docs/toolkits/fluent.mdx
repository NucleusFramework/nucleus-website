[compose-fluent-ui](https://github.com/NucleusFramework/compose-fluent-ui) is a maintained fork of
the Fluent Design library for Compose Multiplatform. Its `decorated-window-fluent` module adds a
Nucleus window with the Windows Mica and Acrylic backdrops. See the
[live gallery](https://nucleusframework.github.io/compose-fluent-ui/).

## Add the dependency

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework.composefluent:fluent:<fluent-version>") // widgets: io.github.composefluent.component
    implementation("dev.nucleusframework.composefluent:fluent-icons-extended:<fluent-version>") // optional
    implementation("dev.nucleusframework.composefluent:decorated-window-fluent:<fluent-version>")
}
```

`decorated-window-fluent` brings `nucleus-application` with it. Pick the release whose README
matches your Nucleus line.

## Open a Fluent window

```kotlin
import dev.nucleusframework.application.nucleusApplication
import dev.nucleusframework.window.fluent.FluentDecoratedWindow
import dev.nucleusframework.window.fluent.FluentTitleBar
import io.github.composefluent.FluentTheme

fun main() = nucleusApplication {
    FluentTheme { // the window reads the Fluent colors for its chrome
        FluentDecoratedWindow(onCloseRequest = ::exitApplication, title = "Settings") {
            FluentTitleBar { /* search, breadcrumbs, … */ }
            App()
        }
    }
}
```
