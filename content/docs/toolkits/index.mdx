A toolkit styles the window chrome and, for the full design systems, the widgets inside it.
macOS 26, Fluent and Yaru are full design systems in their own repositories. Jewel and Material
style the chrome only, and ship with Nucleus.

## Compare the toolkits

| Toolkit | Native to | Artifacts | Ships with |
|---------|-----------|-----------|------------|
| [macOS 26](/docs/toolkits/macos) | macOS Tahoe | `dev.nucleusframework:compose-macos-ui` | Its own repo |
| [Fluent](/docs/toolkits/fluent) | Windows 11 | `dev.nucleusframework.composefluent:fluent` + `decorated-window-fluent` | Its own repo |
| [Yaru](/docs/toolkits/yaru) | Ubuntu / GNOME | `dev.nucleusframework.yarucompose:yaru` + `yaru-decorated-window` | Its own repo |
| [Jewel](/docs/toolkits/jewel) | IntelliJ Platform | `dev.nucleusframework:nucleus.decorated-window-jewel` | Nucleus |
| [Material 2](/docs/toolkits/material) | Any | `dev.nucleusframework:nucleus.decorated-window-material2` | Nucleus |
| [Material 3](/docs/toolkits/material) | Any | `dev.nucleusframework:nucleus.decorated-window-material3` | Nucleus |

The three design-system repos version independently of Nucleus. Pick a release whose README names
your Nucleus line. Live galleries:
[macOS 26](https://nucleusframework.github.io/compose-macos-26-ui/),
[Fluent](https://nucleusframework.github.io/compose-fluent-ui/),
[Yaru](https://nucleusframework.github.io/yaru-compose-ui/).

## Open a toolkit window

Call the toolkit window inside `nucleusApplication { }`. Where the theme goes depends on the
toolkit:

```kotlin
fun main() = nucleusApplication {
    // Fluent, Jewel, Material: the theme wraps the window
    FluentTheme {
        FluentDecoratedWindow(onCloseRequest = ::exitApplication, title = "Settings") {
            FluentTitleBar { /* … */ }
            App()
        }
    }
    // macOS 26, Yaru: the theme goes inside the window
    MacosDecoratedWindow(onCloseRequest = ::exitApplication, title = "Mail") {
        MacosTheme { App() }
    }
}
```

Each toolkit page lists its dependencies and imports.

<Callout type="warn" title="Changed in 3.0">
The Jewel and Material windows and dialogs exist only as `NucleusApplicationScope` extensions. The
overloads on Compose's `ApplicationScope`, and the top-level Material 2 and Jewel dialogs, are gone.
See [Migrate from Nucleus 2.x](/docs/migrate/from-2.x).
</Callout>

To build custom chrome without a toolkit, use [`WindowScaffold`](/docs/windows/window-scaffold).
