[compose-macos-26-ui](https://github.com/NucleusFramework/compose-macos-26-ui) est un design system
Compose Multiplatform au style macOS 26, avec une fenêtre desktop `MacosDecoratedWindow` construite
sur Nucleus. Voir la [galerie en ligne](https://nucleusframework.github.io/compose-macos-26-ui/).

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:compose-macos-ui:<macos-ui-version>")
    // Optionnels : compose-macos-ui-icons-extended, compose-macos-ui-markdown
}
```

Sur la JVM, `compose-macos-ui` apporte `nucleus-application`. Choisissez la version dont le README
correspond à votre ligne de Nucleus.

## Ouvrir une fenêtre décorée

```kotlin
import dev.nucleusframework.application.nucleusApplication
import dev.nucleusframework.macoscompose.theme.MacosTheme
import dev.nucleusframework.macoscompose.window.MacosDecoratedWindow

fun main() = nucleusApplication {
    MacosDecoratedWindow(onCloseRequest = ::exitApplication, title = "Mail") {
        MacosTheme(darkTheme = false) { App() }
    }
}
```

Placez `MacosTheme` dans le contenu de la fenêtre. Les feux tricolores, les matériaux de verre et le
fond de fenêtre suivent alors le thème de l'application plutôt que l'apparence du système. Sous
Windows et Linux, les contrôles de fenêtre de la plateforme occupent la même bande de barre de
titre.
