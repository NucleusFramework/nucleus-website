Un toolkit habille le chrome de la fenêtre et, pour les design systems complets, les widgets
qu'elle contient. macOS 26, Fluent et Yaru sont des design systems complets, chacun dans son propre
dépôt. Jewel et Material n'habillent que le chrome et sont livrés avec Nucleus.

## Comparer les toolkits

| Toolkit | Natif pour | Artefacts | Livré avec |
|---------|------------|-----------|------------|
| [macOS 26](/docs/toolkits/macos) | macOS Tahoe | `dev.nucleusframework:compose-macos-ui` | Son propre dépôt |
| [Fluent](/docs/toolkits/fluent) | Windows 11 | `dev.nucleusframework.composefluent:fluent` + `decorated-window-fluent` | Son propre dépôt |
| [Yaru](/docs/toolkits/yaru) | Ubuntu / GNOME | `dev.nucleusframework.yarucompose:yaru` + `yaru-decorated-window` | Son propre dépôt |
| [Jewel](/docs/toolkits/jewel) | IntelliJ Platform | `dev.nucleusframework:nucleus.decorated-window-jewel` | Nucleus |
| [Material 2](/docs/toolkits/material) | Toutes plateformes | `dev.nucleusframework:nucleus.decorated-window-material2` | Nucleus |
| [Material 3](/docs/toolkits/material) | Toutes plateformes | `dev.nucleusframework:nucleus.decorated-window-material3` | Nucleus |

Les trois dépôts de design systems ont leur propre numéro de version, indépendant de Nucleus.
Choisissez une version dont le README cite votre ligne de Nucleus. Galeries en ligne :
[macOS 26](https://nucleusframework.github.io/compose-macos-26-ui/),
[Fluent](https://nucleusframework.github.io/compose-fluent-ui/),
[Yaru](https://nucleusframework.github.io/yaru-compose-ui/).

## Ouvrir une fenêtre de toolkit

Appelez la fenêtre du toolkit dans `nucleusApplication { }`. L'emplacement du thème dépend du
toolkit :

```kotlin
fun main() = nucleusApplication {
    // Fluent, Jewel, Material : le thème enveloppe la fenêtre
    FluentTheme {
        FluentDecoratedWindow(onCloseRequest = ::exitApplication, title = "Settings") {
            FluentTitleBar { /* … */ }
            App()
        }
    }
    // macOS 26, Yaru : le thème va dans la fenêtre
    MacosDecoratedWindow(onCloseRequest = ::exitApplication, title = "Mail") {
        MacosTheme { App() }
    }
}
```

La page de chaque toolkit liste ses dépendances et ses imports.

<Callout type="warn" title="Modifié en 3.0">
Les fenêtres et dialogues Jewel et Material n'existent plus que comme extensions de
`NucleusApplicationScope`. Les surcharges sur l'`ApplicationScope` de Compose, ainsi que les
dialogues Material 2 et Jewel de premier niveau, ont disparu. Voir
[Migrer depuis Nucleus 2.x](/docs/migrate/from-2.x).
</Callout>

Pour construire un chrome personnalisé sans toolkit, utilisez
[`WindowScaffold`](/docs/windows/window-scaffold).
