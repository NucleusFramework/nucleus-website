[compose-fluent-ui](https://github.com/NucleusFramework/compose-fluent-ui) est un fork maintenu de la
bibliothèque Fluent Design pour Compose Multiplatform. Son module `decorated-window-fluent` ajoute
une fenêtre Nucleus avec les fonds Mica et Acrylic de Windows. Voir la
[galerie en ligne](https://nucleusframework.github.io/compose-fluent-ui/).

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework.composefluent:fluent:<fluent-version>") // widgets : io.github.composefluent.component
    implementation("dev.nucleusframework.composefluent:fluent-icons-extended:<fluent-version>") // optionnel
    implementation("dev.nucleusframework.composefluent:decorated-window-fluent:<fluent-version>")
}
```

`decorated-window-fluent` apporte `nucleus-application`. Choisissez la version dont le README
correspond à votre ligne de Nucleus.

## Ouvrir une fenêtre Fluent

```kotlin
import dev.nucleusframework.application.nucleusApplication
import dev.nucleusframework.window.fluent.FluentDecoratedWindow
import dev.nucleusframework.window.fluent.FluentTitleBar
import io.github.composefluent.FluentTheme

fun main() = nucleusApplication {
    FluentTheme { // la fenêtre lit les couleurs Fluent pour son chrome
        FluentDecoratedWindow(onCloseRequest = ::exitApplication, title = "Settings") {
            FluentTitleBar { /* recherche, fil d'Ariane, … */ }
            App()
        }
    }
}
```
