[compose-macos-26-ui](https://github.com/NucleusFramework/compose-macos-26-ui) is a Compose
Multiplatform design system for the macOS 26 look, with a desktop `MacosDecoratedWindow` built on
Nucleus. See the [live gallery](https://nucleusframework.github.io/compose-macos-26-ui/).

## Add the dependency

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:compose-macos-ui:<macos-ui-version>")
    // Optional: compose-macos-ui-icons-extended, compose-macos-ui-markdown
}
```

On the JVM, `compose-macos-ui` brings `nucleus-application` with it. Pick the release whose README
matches your Nucleus line.

## Open a decorated window

```kotlin
import dev.nucleusframework.application.nucleusApplication
import dev.nucleusframework.macoscompose.theme.MacosTheme
import dev.nucleusframework.macoscompose.window.MacosDecoratedWindow

fun main() = nucleusApplication {
    MacosDecoratedWindow(onCloseRequest = ::exitApplication, title = "Mail") {
        MacosTheme(darkTheme = false) { App() }
    }
}
```

Put `MacosTheme` inside the window content. The traffic lights, glass materials and window
background then follow the app theme instead of the OS appearance. On Windows and Linux the
platform window controls sit in the same title bar band.
