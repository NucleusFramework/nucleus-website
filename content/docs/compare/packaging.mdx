Nucleus builds 18 formats and adds auto-update, signing, sandboxing, CI actions, and GraalVM
native images in one Gradle plugin under Apache 2 and MIT licenses. This page compares it with
jpackage, Compose Multiplatform, Conveyor, install4j, jDeploy, and JavaPackager.

## Auto-update

| Tool | Runtime library | Channels | Verification |
| --- | --- | --- | --- |
| **Nucleus** | `NucleusUpdater` | 3 (latest, beta, alpha) | SHA-512 |
| Conveyor | OS-native (Sparkle 2, MSIX, apt) | Yes | Yes |
| install4j | Updater API | Yes | Yes |
| jDeploy | Built in | No | No |
| jpackage, Compose MP | None | | |

Nucleus and Conveyor both ship delta updates. Nucleus downloads only the changed blocks from any
earlier version, and exposes progress, channel switching, post-update detection, and
restart-on-update.

Every tool compared here signs and notarizes macOS builds. Nucleus also packages GraalVM native
images end to end as DMG, NSIS and DEB. See [GraalVM](/docs/performance/graalvm).

## Pick a tool

- A small CLI or single-window app that needs HSM signing and single-machine builds: **Conveyor**.
- An enterprise installer with custom dialogs and paid support: **install4j**.
- A DMG, MSI or DEB straight from jpackage: **Compose Multiplatform** or **jpackage**.
- One Kotlin codebase for every format and store, with auto-update, AOT and GraalVM: **Nucleus**.

<Callout type="info">
Nucleus builds each OS on its own CI runner, with no cross-compilation. It is Gradle-only, and
younger than Conveyor and install4j.
</Callout>

<Accordions>
<Accordion title="Under the hood">

- Nucleus builds the app image with jpackage, then runs electron-builder's `--prepackaged` mode on
  it for every installer. The plugin downloads the Node.js electron-builder needs.
- Delta updates match electron-builder block maps of the new artifact against a cached copy of
  the previous one, and fetch the missing blocks with HTTP range requests. No pairwise delta files
  exist. Conveyor ships deltas through Sparkle 2 (about 31 KB on macOS).

</Accordion>
</Accordions>
