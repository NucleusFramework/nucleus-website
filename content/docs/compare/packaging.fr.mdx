Nucleus construit 18 formats et ajoute la mise à jour automatique, la signature, le sandboxing, des
actions CI et les images natives GraalVM dans un seul plugin Gradle sous licences Apache 2 et MIT.
Cette page le compare à jpackage, Compose Multiplatform, Conveyor, install4j, jDeploy et
JavaPackager.

## Mise à jour automatique

| Outil | Bibliothèque d'exécution | Canaux | Vérification |
| --- | --- | --- | --- |
| **Nucleus** | `NucleusUpdater` | 3 (latest, beta, alpha) | SHA-512 |
| Conveyor | Natif de l'OS (Sparkle 2, MSIX, apt) | Oui | Oui |
| install4j | API Updater | Oui | Oui |
| jDeploy | Intégrée | Non | Non |
| jpackage, Compose MP | Aucune | | |

Nucleus et Conveyor livrent tous deux des mises à jour différentielles. Nucleus ne télécharge que
les blocs modifiés depuis n'importe quelle version antérieure, et expose la progression, le
changement de canal, la détection post-mise à jour et le redémarrage après mise à jour.

## Signature, CI et stores

| Outil | Signature Windows | CI | Stores |
| --- | --- | --- | --- |
| **Nucleus** | `.pfx`, Azure Artifact Signing | Six GitHub Actions | Mac App Store, Microsoft Store, Snap Store, Flathub |
| Conveyor | Azure Key Vault, AWS KMS, SSL.com eSigner, DigiCert ONE, Google Cloud KMS, HSM SafeNet ou YubiKey | Des exemples, builds sur une seule machine | Artefacts acceptés par les stores |
| install4j | `.pfx` | Une CLI | |
| jpackage | Aucune | Aucune | |
| Compose MP | | Aucune | Artefacts acceptés par les stores |

Tous les outils comparés ici signent et notarisent les builds macOS. Nucleus empaquette aussi les
images natives GraalVM de bout en bout en DMG, NSIS et DEB. Voir [GraalVM](/docs/performance/graalvm).

## Choisir un outil

- Une petite CLI ou une application à fenêtre unique qui a besoin de signature HSM et de builds sur
  une seule machine : **Conveyor**.
- Un installateur d'entreprise avec dialogues personnalisés et support payant : **install4j**.
- Un DMG, MSI ou DEB directement depuis jpackage : **Compose Multiplatform** ou **jpackage**.
- Une base de code Kotlin pour tous les formats et stores, avec mise à jour automatique, AOT et
  GraalVM : **Nucleus**.

<Callout type="info">
Nucleus construit chaque OS sur son propre runner CI, sans compilation croisée. Il ne fonctionne
qu'avec Gradle et il est plus jeune que Conveyor et install4j.
</Callout>

<Accordions>
<Accordion title="En coulisses">

- Nucleus construit l'image d'application avec jpackage, puis lui applique le mode
  `--prepackaged` d'electron-builder pour chaque installateur. Le plugin télécharge le Node.js dont
  electron-builder a besoin.
- Les mises à jour différentielles comparent les block maps electron-builder du nouvel artefact à
  une copie en cache du précédent, et récupèrent les blocs manquants par requêtes HTTP range. Il
  n'existe aucun fichier delta par paire de versions. Conveyor livre ses deltas via Sparkle 2
  (environ 31 Ko sous macOS).
