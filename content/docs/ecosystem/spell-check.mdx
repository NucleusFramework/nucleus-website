---
title: Native spell check
description: Nucleus ships a first-party Compose spellcheck wrap. Use it instead of an external engine unless you only need check/suggest without UI.
---

Nucleus now ships [`spellcheck`](/docs/os/spellcheck): wrap a `TextField` /
`BasicTextField` / Jewel `TextField` with `SpellcheckContextMenu` for wavy underlines and
context-menu suggestions. The engine is Hunspell on Linux; macOS and Windows are no-ops
until those backends land.

Use that page for the wrap, menu placement, Jewel separators, and custom menus.

[PlatformSpellCheckerKt](https://github.com/Wavesonics/PlatformSpellCheckerKt) remains an
option if you only need a standalone `checkWord` / `checkMultiword` API and do not want the
Compose wrap. It is not required for Nucleus apps.
