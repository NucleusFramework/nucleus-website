---
title: Correcteur orthographique natif
description: Nucleus livre un wrap Compose first-party. Utilisez-le à la place d'un moteur externe, sauf si vous n'avez besoin que de check/suggest sans UI.
---

Nucleus livre désormais [`spellcheck`](/docs/os/spellcheck) : encadrez un `TextField` /
`BasicTextField` / `TextField` Jewel avec `SpellcheckContextMenu` pour le soulignement
ondulé et les suggestions du menu contextuel. Le moteur est Hunspell sous Linux ; macOS et
Windows sont des no-ops jusqu'à ce que ces backends arrivent.

La page dédiée couvre le wrap, le placement du menu, les séparateurs Jewel et les menus
custom.

[PlatformSpellCheckerKt](https://github.com/Wavesonics/PlatformSpellCheckerKt) reste une
option si vous n'avez besoin que d'une API autonome `checkWord` / `checkMultiword` et pas
du wrap Compose. Elle n'est pas requise pour une application Nucleus.
