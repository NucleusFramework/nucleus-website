Les modules Nucleus sortent ensemble sous le groupe `dev.nucleusframework`. `nucleus-application`
apporte le point d'entrée, les fenêtres et l'essentiel du runtime. Ajoutez un autre module quand
votre application en a besoin, dans la même version :

```kotlin title="build.gradle.kts"
val nucleusVersion = "<version>"

dependencies {
    implementation(compose.desktop.currentOs)
    implementation("dev.nucleusframework:nucleus.nucleus-application:$nucleusVersion")
    implementation("dev.nucleusframework:nucleus.notification-common:$nucleusVersion")
    implementation("dev.nucleusframework:nucleus.global-hotkey:$nucleusVersion")
}
```

## Ce qu'apporte nucleus-application

Les fenêtres, dialogues, popups et contenus natifs, les thèmes et icônes de fenêtre, la détection
de plateforme, les métadonnées `NucleusApp`, l'instance unique, les liens profonds, le cache AOT,
`isSystemInDarkMode()` et la [correction orthographique](/docs/os/spell-check). Le menu contextuel
natif de macOS, `Modifier.keepScreenOn()` et la prise en charge de l'image native viennent aussi
avec.

<Callout type="warn" title="Modifié en 3.0">
`nucleus-application` expose `decorated-window-tao` : retirez votre propre dépendance à
`decorated-window-tao`. `decorated-window-awt`, `decorated-window-jbr` et `decorated-window-jni`
n'existent plus. Voir [Migrer depuis 2.x](/docs/migrate/from-2.x).
</Callout>

## Modules de toolkit

`decorated-window-jewel` (Java 25), `decorated-window-material2` et `decorated-window-material3`
habillent fenêtres et dialogues dans `nucleusApplication`. macOS 26, Fluent et Yaru vivent dans
leurs propres dépôts. Voir [Toolkits](/docs/toolkits).

## Modules d'intégration OS

| Fonctionnalité | Module |
|---|---|
| Notifications, un seul DSL pour tous les OS | [`notification-common`](/docs/os/notifications) (apporte les modules par OS) |
| Notifications par OS | `notification-macos`, `notification-windows`, `notification-linux` |
| Menu du Dock (macOS) | `launcher-macos` |
| Jump lists et boutons de barre des tâches (Windows) | `launcher-windows` |
| Quicklist Unity (Linux) | `launcher-linux` |
| Barre de menus native (macOS) | `menu-macos` |
| Progression dans la barre des tâches | `taskbar-progress`, [`taskbar-progress-tao`](/docs/os/dock-taskbar/progress) |
| Couleur d'accent du système | `system-color` |
| Raccourcis clavier globaux | `global-hotkey` |
| Contrôles multimédias (Now Playing, SMTC, MPRIS) | `media-control` |
| Informations système (CPU, RAM, GPU, batteries) | `system-info` |
| Catalogue SF Symbols | [`sf-symbols`](/docs/os/icons/sf-symbols) |
| Noms d'icônes FreeDesktop | `freedesktop-icons` |

## Modules de cycle de vie

| Fonctionnalité | Module |
|---|---|
| Lancement à l'ouverture de session | `autolaunch` |
| Tâches planifiées (cron, périodiques, au démarrage) | `scheduler` |
| Tests du scheduler sur une horloge virtuelle | [`scheduler-testing`](/docs/lifecycle/background/scheduler-testing) |
| Surveillance du système de fichiers | [`fs-watcher`](/docs/lifecycle/fs-watcher) |
| Éléments de connexion, launch agents et daemons (macOS) | `service-management-macos` |
| Mode efficacité et maintien de l'écran allumé | `energy-manager` |
| Mise à jour automatique | [`updater-runtime`](/docs/packaging/auto-update) |

## Modules de performance et de réseau

| Fonctionnalité | Module |
|---|---|
| Trust manager adossé au magasin de certificats de l'OS | `native-ssl` |
| `java.net.http.HttpClient` avec la confiance native | [`native-http`](/docs/performance/native-http) |
| OkHttp avec la confiance native | `native-http-okhttp` |
| Ktor avec la confiance native | `native-http-ktor` |
| Détection de l'échelle HiDPI sous Linux | `linux-hidpi` |

Les trois modules `native-http` apportent `native-ssl`.

<Accordion title="En coulisses">

- Sur le classpath de compilation, `nucleus-application` apporte `decorated-window-tao`,
  `decorated-window-core`, `core-runtime`, `aot-runtime`, `darkmode-detector` et `spellcheck`.
- À l'exécution seulement, il ajoute `graalvm-runtime` (avec `linux-hidpi`), `menu-macos` (avec
  `sf-symbols`), `energy-manager` et `angle-natives`. Déclarez l'un d'eux pour importer son API.
- Les modules de notification, de launcher et de contrôles multimédias livrent leurs callbacks via
  `NucleusUiThread`. Voir [Threading](/docs/concepts/threading).
- Les modules lisent l'identité de votre application via `NucleusApp.appId`, `NucleusApp.version`
  et les autres propriétés que le plugin Gradle écrit au build.
