title: Runtimes et performance
description: Compilez le même code Kotlin en image native GraalVM ou en image JDK avec cache AOT, choisissez le bon runtime et détectez-le depuis le code.
---

Nucleus produit deux runtimes à partir d'un même code Kotlin : une image native GraalVM, ou une
image JDK accompagnée d'un cache AOT (ahead-of-time). Vous choisissez le runtime dans
`build.gradle.kts`, sans toucher à votre code.

## Comparer les runtimes

|                     | GraalVM Native Image              | JDK + cache AOT                                |
|---------------------|-----------------------------------|------------------------------------------------|
| Démarrage et exécution | Démarrage rapide, moins de mémoire | Plus rapide une fois les chemins chauds compilés par HotSpot |
| Fonctions dynamiques| Déclarées à la compilation        | Réflexion, chargement de classes, agents, JFR  |
| JDK minimal         | GraalVM 25, fourni par le plugin  | JDK 25 pour le cache AOT                       |
| Convient à          | Applications de barre d'état ou de menus, utilitaires, lanceurs, builds pour les stores | Outils de type IDE, calculs lourds, hôtes de plugins, moteurs de script |

Les deux peuvent cohabiter dans un projet : publiez une image native sur un store et une image JDK
en téléchargement direct.

## Passer d'un runtime à l'autre

```kotlin title="build.gradle.kts"
nucleus.application {
    mainClass = "com.example.MainKt"

    // Image native GraalVM
    graalvm {
        isEnabled = true
        imageName = "myapp"
    }

    // Image JDK avec cache AOT
    nativeDistributions {
        enableAotCache = true
    }
}
```

Les tâches JVM (`packageDistributionForCurrentOS`, …) produisent l'image JDK, et les tâches
GraalVM (`packageGraalvmNativeDistributionForCurrentOS`, …) produisent l'image native. Côté JVM,
ajoutez `nucleusOptimization = true` pour un démarrage à froid plus court : voir
[Optimisation du démarrage](/docs/performance/startup).

## Détecter le runtime à l'exécution

```kotlin
import dev.nucleusframework.aot.runtime.AotRuntime
import dev.nucleusframework.aot.runtime.AotRuntimeMode
import dev.nucleusframework.core.runtime.ExecutableRuntime

when (AotRuntime.mode()) {
    AotRuntimeMode.TRAINING -> { /* entraînement AOT : sautez le travail visible */ }
    AotRuntimeMode.RUNTIME -> { /* lancé avec un cache AOT */ }
    AotRuntimeMode.OFF -> { /* JVM simple ou image native */ }
}

val isNative: Boolean = ExecutableRuntime.isGraalVmNativeImage
```

`ExecutableRuntime.type()` renvoie le format de paquet (`DMG`, `MSI`, `DEB`, `DEV`, etc.). Voir
[Type d'exécutable](/docs/lifecycle/executable-type).
