title: Runtimes and performance
description: Build the same Kotlin source as a GraalVM native image or as a JDK image with an AOT cache, pick the right one, and detect the runtime from code.
---

Nucleus builds one Kotlin source tree into two runtimes: a GraalVM native image, or a JDK image
with an ahead-of-time (AOT) cache. You pick the runtime in `build.gradle.kts`, and your code stays
the same.

## Compare the runtimes

|                    | GraalVM Native Image              | JDK + AOT cache                           |
|--------------------|-----------------------------------|-------------------------------------------|
| Starts and runs    | Fast start, less memory           | Faster once HotSpot compiles hot paths    |
| Dynamic features   | Declared at build time            | Reflection, class loading, agents, JFR    |
| Minimum JDK        | GraalVM 25, provisioned for you   | JDK 25 for the AOT cache                  |
| Fits               | Tray and menu-bar apps, utilities, launchers, store builds | IDE-like tools, CPU-heavy work, plugin hosts, scripting engines |

Both can live in one project: ship a native image to a store and a JDK build for direct download.

## Switch between runtimes

```kotlin title="build.gradle.kts"
nucleus.application {
    mainClass = "com.example.MainKt"

    // GraalVM native image
    graalvm {
        isEnabled = true
        imageName = "myapp"
    }

    // JDK image with an AOT cache
    nativeDistributions {
        enableAotCache = true
    }
}
```

The JVM tasks (`packageDistributionForCurrentOS`, …) produce the JDK image, and the GraalVM tasks
(`packageGraalvmNativeDistributionForCurrentOS`, …) produce the native one. On the JVM path, add
`nucleusOptimization = true` for a faster cold start: see [Startup optimization](/docs/performance/startup).

## Detect the runtime at run time

```kotlin
import dev.nucleusframework.aot.runtime.AotRuntime
import dev.nucleusframework.aot.runtime.AotRuntimeMode
import dev.nucleusframework.core.runtime.ExecutableRuntime

when (AotRuntime.mode()) {
    AotRuntimeMode.TRAINING -> { /* AOT training run: skip user-facing work */ }
    AotRuntimeMode.RUNTIME -> { /* launched with an AOT cache */ }
    AotRuntimeMode.OFF -> { /* plain JVM or native image */ }
}

val isNative: Boolean = ExecutableRuntime.isGraalVmNativeImage
```

`ExecutableRuntime.type()` returns the package format (`DMG`, `MSI`, `DEB`, `DEV` and others). See
[Executable type](/docs/lifecycle/executable-type).
