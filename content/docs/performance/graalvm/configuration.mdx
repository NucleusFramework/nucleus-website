The `graalvm { }` block inside `nucleus.application { }` configures native-image builds. Set
`isEnabled = true` and the plugin provisions everything else:

```kotlin title="build.gradle.kts"
nucleus.application {
    mainClass = "com.example.MainKt"
    graalvm {
        isEnabled = true
        imageName = "myapp"
        optimization = NativeImageOptimization.SIZE // optional, default -O2
    }
}
```

## Build a headless image

For a daemon or a CLI, set `headless = true`. The image leaves out AWT, Java2D, Skiko and Compose
and runs with `-Djava.awt.headless=true`. Keep `false` for any app with a window or a tray icon.

## Provision the toolchain

The plugin downloads **GraalVM Community Edition** into `<gradle-user-home>/nucleus/graalvm` on the
first native-image task. A `GRAALVM_HOME` that matches the requested distribution wins.

```kotlin title="build.gradle.kts"
graalvm {
    toolchain {
        distribution = GraalvmDistribution.COMMUNITY // default, or ORACLE
        channel = GraalvmChannel.INNOVATION          // default 25i4; LTS gives 25
        // version = "25.0.1"                        // overrides channel
    }
}
```

- `autoDownload = false` resolves through Gradle toolchains (`javaLanguageVersion`, `jvmVendor`)
  instead. Use it, or `GRAALVM_HOME`, for Liberica NIK or Mandrel.
- Intel Macs get BellSoft Liberica NIK 25.0.x (`macosIntelFallback`), since GraalVM stopped
  shipping Intel macOS after 25.0.1.
- Floating versions (`"25"`, `"25i4"`) stick once downloaded. Delete their folder under
  `installDir` to update.

### Roll back to GraalVM 25.3

If a build regresses on the default `25i4`, set `toolchain { version = "25i3" }`.

### Choose a distribution

Oracle GraalVM adds Profile-Guided Optimization, `-O3`, ML-inferred profiles,
`advancedObfuscation` and the G1 collector. On Community Edition the build skips those with a
warning.

## Choose a garbage collector

A native image fixes its collector at build time. Serial, the default, fits desktop heaps. Pick G1
once the heap passes roughly 1 to 2 GB.

```kotlin title="build.gradle.kts"
nucleus.application {
    garbageCollector = GarbageCollector.Z                  // JVM distribution and run task
    graalvm {
        garbageCollector = NativeImageGarbageCollector.G1  // baked into the image
    }
}
```

| `NativeImageGarbageCollector` | Availability |
|-------------------------------|--------------|
| `SERIAL` | Every toolchain. The default. |
| `G1` | Oracle GraalVM only. Linux from 25.0; Windows and macOS from 25.4. Falls back to Serial with a warning elsewhere. |
| `EPSILON` | Never reclaims memory. Benchmarks and short-lived processes only. |

An explicit `-XX:+Use…GC` in `jvmArgs` wins over the JVM-side `garbageCollector`. The
[startup pack](/docs/performance/startup) also turns on [idle GC](/docs/performance/startup#idle-gc)
in the native image.

## Catch missing registrations in the dev loop

`runGraalvmNative` runs with `--exact-reachability-metadata` for the packages in
`exactReachabilityMetadata`. An unregistered lookup there throws
`MissingReflectionRegistrationError` naming the missing element. Distributable and packaging tasks
never get the flag.

```kotlin title="build.gradle.kts"
graalvm {
    exactReachabilityMetadata = ExactReachabilityMetadata.APP_PACKAGES // default: mainClass package
    // ExactReachabilityMetadata.packages("com.example", "com.example.shared")
    // ExactReachabilityMetadata.OFF
}
```

Pass `-Pnucleus.graalvm.missingRegistration=warn|exit|throw` (default `warn`) to list every missing
registration in one run.

## Set build arguments

`buildArgs` go to `native-image` as is and win over the typed properties. Use them for flags with
no property, such as `-H:-IncludeMethodData` (saves several MB). Nucleus initializes SLF4J at run
time; to move it to build time with a fixed backend, add
`buildArgs.add("--initialize-at-build-time=org.slf4j")`.

## Optimize with a PGO profile

Profile-Guided Optimization needs Oracle GraalVM.

1. Run `./gradlew runWithPgoInstrument`, exercise the hot paths, then quit. The profile lands in
   `pgo { profile }` (default `graalvm/pgo/default.iprof`).
2. Commit the `.iprof` file. Full builds and packaging tasks apply it; `runGraalvmNative` does not.

Pass `-Pnucleus.graalvm.pgo=off` to build once without it, or set `pgo { enabled = false }`.

## Configure the metadata repository

```kotlin title="build.gradle.kts"
graalvm {
    metadataRepository {
        // enabled = true, version = "1.1.4" by default
        moduleToConfigVersion.put("io.ktor:ktor-client-core", "3.0.0")
        excludedModules.add("com.example:noisy-lib")
    }
}
```

## Configure macOS and Windows

- `macOS { minimumSystemVersion }` defaults to `"12.0"`. `macOsSdkVersion` defaults to `"26.0"`;
  Liquid Glass needs SDK 26. `cStubsSrc` links extra C stubs.
- On Windows the plugin copies `vcruntime140.dll`, `vcruntime140_1.dll` and `msvcp140.dll` next to
  the `.exe`, so the app needs no Visual C++ Redistributable. Tune it with
  `windows { bundleCRuntime; dlls; sourceDir }`.

## No release variant

There is no `packageReleaseGraalvmNative`. `native-image` already removes dead code, and ProGuard
could rename classes the metadata references. Use `NativeImageOptimization.SIZE` to shrink.

<Accordions>
<Accordion title="Under the hood">

- A headless build skips the platform metadata and the GUI packs (`jdk-awt`, `jdk-fonts`,
  `jdk-graphics2d`, Skiko, Compose, tray, media player, webview) and copies no GUI libraries.
- Install folders carry the distribution name (`graalvm-community-jdk-*`, `graalvm-jdk-*`). A
  `GRAALVM_HOME` of the other distribution is ignored with a warning.
- The plugin reads `GRAALVM_VERSION` from the toolchain's `release` file to decide on G1. GraalVM
  25.3 fails to link G1 on Windows and macOS (`g1gc-cr.lib`).
- `maxHeapSizePercent` becomes `-R:MaximumHeapSizePercent` (Serial, Epsilon) or
  `-R:MaxRAMPercentage` (G1).
- Before JDK 23, exact reachability falls back to `-H:ThrowMissingRegistrationErrors=` or is
  skipped.
- On Linux and macOS the plugin strips the executable, which saves tens of MB.

</Accordion>

## graalvm { } reference

| Property | Default | Notes |
|----------|---------|-------|
| `isEnabled` | `false` | Master switch. |
| `headless` | `false` | See [Build a headless image](#build-a-headless-image). |
| `imageName` | package name | Output binary name. |
| `march` | per platform | `NATIVE` targets the build CPU, `COMPATIBILITY` older CPUs. Unset means `COMPATIBILITY`, except `NATIVE` on Apple Silicon. |
| `optimization` | `-O2` | `QUICK_BUILD` (`-Ob`), `NONE`, `LEVEL_1`, `LEVEL_2`, `LEVEL_3` (Oracle), `SIZE` (`-Os`). |
| `allCharsets` | `false` | Adds `-H:+AddAllCharsets`. Legacy encodings only. |
| `mlProfileInference` | `true` | `false` adds `-H:-MLProfileInference`. Oracle only. |
| `advancedObfuscation` | `false` | Adds `-H:AdvancedObfuscation=`. Oracle only. |
| `autoIncludeResources` | `true` | Bundle resources of the project and its `project(...)` dependencies. |
| `maxHeapSizePercent` | `25` | Default max heap as a percent of RAM. |
| `maxHeapSize` | unset | Absolute max heap (`"2g"`). Wins over the percent. |
| `garbageCollector` | Serial | See [Choose a garbage collector](#choose-a-garbage-collector). |
| `exactReachabilityMetadata` | `APP_PACKAGES` | `runGraalvmNative` only. See [above](#catch-missing-registrations-in-the-dev-loop). |
| `detectOrphanProjectClasses` | `true` | See [Automatic metadata](/docs/performance/graalvm/automatic-metadata#detect-orphan-project-classes). |
| `reflectionForProjectClasses` | `false` | Registers every project class with a public no-arg constructor. Grows the image. |
| `buildArgs` | empty | Appended verbatim. |
| `javaLanguageVersion`, `jvmVendor` | `25`, unset | With `toolchain { autoDownload = false }` only. |
| `nativeImageConfigBaseDir` | unset | Folder of your own `reachability-metadata.json`. |
| `toolchain { }` | auto-download | See [Provision the toolchain](#provision-the-toolchain). |
| `pgo { }` | enabled | See [Optimize with a PGO profile](#optimize-with-a-pgo-profile). |
| `metadataRepository { }` | enabled | See [Configure the metadata repository](#configure-the-metadata-repository). |
| `macOS { }`, `windows { }` | | See [Configure macOS and Windows](#configure-macos-and-windows). |
