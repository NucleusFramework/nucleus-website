## Stabilize the tool window APIs

Satellites, `DockLayout`, and the tab workspace are `@ExperimentalNucleusApi` in 3.0, and their
surface may change without a deprecation cycle. The opt-in goes away once the API holds across
real apps. See [Tool windows](/docs/tool-windows).

## Known gaps

- **Native dialog modality on macOS and Linux.** Windows disables the owner of a
  `DecoratedDialog`; macOS and Linux only block pointer input inside the scene. See [Block the
  owner](/docs/windows/dialogs-popups#block-the-owner).
- **PAC scripts on Linux.** [`native-proxy`](/docs/performance/native-proxy) applies static rules
  and bypass lists only there, and is not wired into the [Native HTTP](/docs/performance/native-http)
  clients yet.
- **macOS window id for capture.** Tao does not expose a window's `CGWindowID`, so
  [screen capture](/docs/os/screen-capture#capture-a-window) of your own window looks it up in
  `windows()`.
- **Occlusion on Windows and Linux.** A covered or hidden window stops rendering on macOS only.
  See [Idle windows](/docs/performance/rendering#idle-windows).

## Waiting on upstream

- **Compose window API v2 types.** Nucleus ships an AWT-free copy in
  `dev.nucleusframework.window.tao.v2`. If JetBrains decouples the upstream types from AWT, you
  will import those instead.
- **Pinch and rotation in Compose gestures.** In Compose 1.12, `detectTransformGestures` does not
  see `Scale` events, and Compose has no rotation event.
- **Tao updates.** Fixes from Tao releases after 0.35 reach Nucleus by hand.

## Under consideration

No commitment and no date. Open an issue if you need one of these:

| Module | Description |
| --- | --- |
| `clipboard` | HTML and RTF clipboard flavors and a change watcher. Text, images and file lists already work, see [Linux and Wayland](/docs/windows/linux-wayland). |
| Screen recording | Video capture of a display or a window. Still images already work, see [Screen capture](/docs/os/screen-capture). |
| Volume events | Volume UUIDs, internal, external and network classification, and mount, unmount and eject events in `system-info` |
| In-app purchases | StoreKit 2 and Microsoft Store purchases |

## Influence the order

Open an issue that describes your use case, link a sample app that needs the module, or sponsor
the implementation for one platform. The modules more people ask for ship first.
