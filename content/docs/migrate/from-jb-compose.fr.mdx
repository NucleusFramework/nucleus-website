import { Callout } from 'fumadocs-ui/components/callout';

Portez une application JetBrains Compose Desktop vers Nucleus : ajoutez le plugin, renommez le
bloc d'application et remplacez les fenêtres AWT par `DecoratedWindow`.

<Callout type="info" title="Confier la migration à un agent">
Un agent IA peut mener toute la migration. Voir [Migrer avec un agent IA](/docs/migrate/ai-agent).
</Callout>

## Avant de commencer

- Compose Multiplatform 1.12 ou plus récent et JDK 17 ou plus récent.
- La liste des API AWT et Swing qu'utilise votre interface (`Window`, `DialogWindow`, `Tray`,
  `SwingPanel`, `JFileChooser`, `MenuBar`). Les fenêtres Nucleus ne sont pas des fenêtres AWT :
  chacune demande un remplacement.

## Ajouter le plugin

Gardez le plugin JetBrains Compose : Nucleus l'étend.

```diff title="build.gradle.kts"
 plugins {
     id("org.jetbrains.compose") version "1.12.1"
+    id("dev.nucleusframework") version "<version>"
 }
```

## Passer le build au DSL Nucleus

1. Changez les imports du DSL (`TargetFormat`, `CompressionLevel`, `SigningAlgorithm` et les
   autres) : `org.jetbrains.compose.desktop.application.dsl` devient
   `dev.nucleusframework.desktop.application.dsl`.
2. Renommez `compose.desktop.application { }` en `nucleus.application { }`. Les deux blocs ne
   peuvent pas coexister. Chaque réglage à l'intérieur reste identique.
3. Renseignez `homepage`. Sans lui, `packageDeb` et `packageGraalvmDeb` échouent avec
   `Please specify project homepage`.

```diff title="build.gradle.kts"
-compose.desktop.application {
+nucleus.application {
     mainClass = "com.example.MainKt"
     nativeDistributions {
+        homepage = "https://myapp.example.com"
     }
 }
```

Le reste du build et les tâches Gradle existantes (`run`, `packageDmg`, `packageDeb`)
fonctionnent sans changement,
[Compose Hot Reload](https://kotlinlang.org/docs/multiplatform/compose-hot-reload.html) compris.

## Remplacer le point d'entrée et les fenêtres

Ajoutez `nucleus-application`, qui apporte le point d'entrée et le runtime de fenêtres. Voir
[Modules](/docs/concepts/modules) pour les modules optionnels.

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.nucleus-application:<version>")
}
```

Remplacez `application { }` par `nucleusApplication { }` et `Window` par `DecoratedWindow`.
Gardez les sorties anticipées en ligne de commande au-dessus de `nucleusApplication`.

```diff
-import androidx.compose.ui.window.Window
-import androidx.compose.ui.window.application
+import dev.nucleusframework.application.DecoratedWindow
+import dev.nucleusframework.application.nucleusApplication
+import dev.nucleusframework.window.TitleBar

-fun main() = application {
-    Window(onCloseRequest = ::exitApplication, title = "MyApp") {
+fun main(args: Array<String>) = nucleusApplication(args) {
+    DecoratedWindow(onCloseRequest = ::exitApplication, title = "MyApp") {
+        TitleBar { Text(title) }
         App()
     }
 }
```

Remplacez ensuite chaque API AWT. `Window`, `DialogWindow` et `Tray` de Compose Desktop échouent
sous `nucleusApplication` :

| Compose Desktop (AWT) | Nucleus |
| --- | --- |
| `Window(…)` | [`DecoratedWindow(…)`](/docs/windows) |
| `DialogWindow(…)` | [`DecoratedDialog(…)`](/docs/windows/dialogs-popups) |
| `Tray(…)` | `Tray(…)` de [ComposeNativeTray](/docs/os/tray) |
| `MenuBar { }` | [`menu-macos`](/docs/os/menus/menu-bar) pour le menu d'application macOS |
| `SwingPanel`, `Canvas` AWT | [`NativeView`](/docs/native-content/native-views) |
| `JFileChooser`, `java.awt.FileDialog` | [FileKit](/docs/os/file-dialogs) |
| `window.window` (`ComposeWindow`) | `nucleusWindow` et `LocalNucleusWindow` |
| `rememberWindowState()` de `androidx.compose.ui.window.v2` | la même fonction de [`dev.nucleusframework.window.tao.v2`](/docs/windows/window-state) |

Pour une apparence Material 3, Material 2 ou Jewel, utilisez `MaterialDecoratedWindow` ou
`JewelDecoratedWindow` ([Toolkits](/docs/toolkits)). Les classes AWT sans fenêtre continuent de
fonctionner : `BufferedImage`, `ImageIO`, `java.awt.Font` et le presse-papiers AWT.

## Lancer l'application

Lancez `./gradlew run`, puis vérifiez la barre de titre, le déplacement de la fenêtre, la
réduction et le plein écran, les fenêtres secondaires et chaque dialogue porté.

## Activer les fonctionnalités de packaging de Nucleus

Ces réglages sont opt-in. Le packaging ne demande pas Node.js sur la machine.

```kotlin title="build.gradle.kts"
nucleus.application {
    nativeDistributions {
        targetFormats(TargetFormat.Dmg, TargetFormat.Nsis, TargetFormat.AppImage, TargetFormat.Flatpak)
        cleanupNativeLibs = true
        enableAotCache = true
        splashImage = "splash.png"
        protocol("MyApp", "myapp")
        publish { github { enabled = true; owner = "myorg"; repo = "myapp" } }
    }
}
```

Voir [Packaging](/docs/packaging) pour toutes les options, et
[Nucleus et Compose Multiplatform seul](/docs/compare/cmp-default#ce-que-nucleus-ajoute) pour ce
que chaque fonctionnalité apporte par rapport à Compose Desktop.
