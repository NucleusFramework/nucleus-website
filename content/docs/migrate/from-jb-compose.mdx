Move a JetBrains Compose Desktop app to Nucleus: add the plugin, rename the application block,
and replace the AWT windows with `DecoratedWindow`.

<Callout type="info" title="Let an agent do it">
An AI coding agent can run the whole migration. See [Migrate with an AI agent](/docs/migrate/ai-agent).
</Callout>

## Before you start

- Compose Multiplatform 1.12 or later and JDK 17 or later.
- The list of AWT and Swing APIs your UI uses (`Window`, `DialogWindow`, `Tray`, `SwingPanel`,
  `JFileChooser`, `MenuBar`). Nucleus windows are not AWT windows, so each one needs a replacement.

## Add the plugin

Keep the JetBrains Compose plugin: Nucleus extends it.

```diff title="build.gradle.kts"
 plugins {
     id("org.jetbrains.compose") version "1.12.0"
+    id("dev.nucleusframework") version "<version>"
 }
```

## Move the build to the Nucleus DSL

1. Swap the DSL imports (`TargetFormat`, `CompressionLevel`, `SigningAlgorithm`, and the others):
   `org.jetbrains.compose.desktop.application.dsl` becomes `dev.nucleusframework.desktop.application.dsl`.
2. Rename `compose.desktop.application { }` to `nucleus.application { }`. The two blocks cannot
   coexist. Every setting inside stays the same.
3. Set `homepage`. Without it, `packageDeb` and `packageGraalvmDeb` fail with
   `Please specify project homepage`.

```diff title="build.gradle.kts"
-compose.desktop.application {
+nucleus.application {
     mainClass = "com.example.MainKt"
     nativeDistributions {
+        homepage = "https://myapp.example.com"
     }
 }
```

The rest of the build and the existing Gradle tasks (`run`, `packageDmg`, `packageDeb`) work
unchanged, [Compose Hot Reload](https://kotlinlang.org/docs/multiplatform/compose-hot-reload.html)
included.

## Replace the entry point and windows

Add `nucleus-application`, which brings the entry point and the window runtime. See
[Modules](/docs/concepts/modules) for the optional ones.

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.nucleus-application:<version>")
}
```

Swap `application { }` for `nucleusApplication { }` and `Window` for `DecoratedWindow`. Keep
command-line early exits above `nucleusApplication`.

```diff
-import androidx.compose.ui.window.Window
-import androidx.compose.ui.window.application
+import dev.nucleusframework.application.DecoratedWindow
+import dev.nucleusframework.application.nucleusApplication
+import dev.nucleusframework.window.TitleBar

-fun main() = application {
-    Window(onCloseRequest = ::exitApplication, title = "MyApp") {
+fun main(args: Array<String>) = nucleusApplication(args) {
+    DecoratedWindow(onCloseRequest = ::exitApplication, title = "MyApp") {
+        TitleBar { Text(title) }
         App()
     }
 }
```

Then replace each AWT API. Compose Desktop's `Window`, `DialogWindow` and `Tray` fail under
`nucleusApplication`:

| Compose Desktop (AWT) | Nucleus |
| --- | --- |
| `Window(…)` | [`DecoratedWindow(…)`](/docs/windows) |
| `DialogWindow(…)` | [`DecoratedDialog(…)`](/docs/windows/dialogs-popups) |
| `Tray(…)` | `Tray(…)` from [ComposeNativeTray](/docs/os/tray) |
| `MenuBar { }` | [`menu-macos`](/docs/os/menus/menu-bar) for the macOS app menu |
| `SwingPanel`, AWT `Canvas` | [`NativeView`](/docs/native-content/native-views) |
| `JFileChooser`, `java.awt.FileDialog` | [FileKit](/docs/os/file-dialogs) |
| `window.window` (`ComposeWindow`) | `nucleusWindow` and `LocalNucleusWindow` |
| `rememberWindowState()` from `androidx.compose.ui.window.v2` | the same function from [`dev.nucleusframework.window.tao.v2`](/docs/windows/window-state) |

For a Material 3, Material 2 or Jewel look, use `MaterialDecoratedWindow` or
`JewelDecoratedWindow` ([Toolkits](/docs/toolkits)). AWT classes that need no window keep
working: `BufferedImage`, `ImageIO`, `java.awt.Font`, and the AWT clipboard.

## Run the app

Run `./gradlew run`, then check the title bar, window drag, minimize and fullscreen, secondary
windows, and each dialog you ported.

## Enable Nucleus packaging features

These settings are opt-in. Packaging needs no Node.js on the machine.

```kotlin title="build.gradle.kts"
nucleus.application {
    nativeDistributions {
        targetFormats(TargetFormat.Dmg, TargetFormat.Nsis, TargetFormat.AppImage, TargetFormat.Flatpak)
        cleanupNativeLibs = true
        enableAotCache = true
        splashImage = "splash.png"
        protocol("MyApp", "myapp")
        publish { github { enabled = true; owner = "myorg"; repo = "myapp" } }
    }
}
```

See [Packaging](/docs/packaging) for every option, and
[Nucleus and vanilla Compose Multiplatform](/docs/compare/cmp-default#what-nucleus-adds) for
what each feature adds over Compose Desktop.
