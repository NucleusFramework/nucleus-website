import { Callout } from 'fumadocs-ui/components/callout';

Paste one prompt into an AI coding agent such as Claude Code, Cursor, or Codex, inside your
project, and review each step it makes.

## Upgrade a Nucleus 2.x app to 3.0

The prompt applies the [2.x to 3.0 checklist](/docs/migrate/from-2.x):

```text
Fetch https://nucleusframework.dev/en/docs/migrate/from-2.x and apply it to this project.
Work through the checklist group by group: compile errors first, then runtime behavior
changes, then build and CI. After each group, run ./gradlew build and stop so I can check
the app before you continue.
```

Ask the agent to list the rows that don't apply, so you can confirm them. Retest quit flows on
macOS, trackpad gestures, and close handlers yourself.

## Migrate a JetBrains Compose Desktop app

```text
Fetch https://nucleusframework.dev/nucleus-migrate.md and follow its instructions to
analyze this app and migrate it to Nucleus step by step.
```

The agent scans the app for AWT, Swing and packaging usage, asks which design system and native
features you want, then migrates one phase at a time: Gradle DSL, window shell, AWT removal,
features, packaging, GraalVM, CI. Each phase ends with a checkpoint, and a final report lists what
changed.

<Callout type="warn">
Nucleus 3.0 has no AWT window backend. If the agent adds `decorated-window-jbr` or
`decorated-window-jni`, refuse and point it at [Migrate from Nucleus 2.x to 3.0](/docs/migrate/from-2.x).
</Callout>

## Install the playbook as a Claude Code skill

Download [nucleus-migrate.skill](https://nucleusframework.dev/nucleus-migrate.skill) and unzip it
into your skills directory:

```shell
cd ~/.claude/skills && unzip ~/Downloads/nucleus-migrate.skill
```

Run `/nucleus-migrate`, or ask Claude Code to migrate the app to Nucleus.
