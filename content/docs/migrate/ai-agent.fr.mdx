import { Callout } from 'fumadocs-ui/components/callout';

Collez un seul prompt dans un agent de code IA comme Claude Code, Cursor ou Codex, ouvert dans votre
projet, et relisez chaque étape qu'il effectue.

## Passer une application Nucleus 2.x à 3.0

Le prompt applique la [liste de contrôle 2.x vers 3.0](/docs/migrate/from-2.x) :

```text
Fetch https://nucleusframework.dev/en/docs/migrate/from-2.x and apply it to this project.
Work through the checklist group by group: compile errors first, then runtime behavior
changes, then build and CI. After each group, run ./gradlew build and stop so I can check
the app before you continue.
```

Demandez à l'agent de lister les lignes qui ne s'appliquent pas, pour les confirmer. Retestez
vous-même la sortie de l'application sous macOS, les gestes du trackpad et les gestionnaires de
fermeture.

## Migrer une application JetBrains Compose Desktop

```text
Fetch https://nucleusframework.dev/nucleus-migrate.md and follow its instructions to
analyze this app and migrate it to Nucleus step by step.
```

L'agent analyse l'usage d'AWT, de Swing et du packaging, vous demande quel design system et quelles
fonctionnalités natives vous voulez, puis migre une phase à la fois : DSL Gradle, fenêtre, retrait
d'AWT, fonctionnalités, packaging, GraalVM, CI. Chaque phase se termine par un point de contrôle,
et un rapport final liste ce qui a changé.

<Callout type="warn">
Nucleus 3.0 n'a pas de backend de fenêtres AWT. Si l'agent ajoute `decorated-window-jbr` ou
`decorated-window-jni`, refusez et renvoyez-le vers
[Migrer de Nucleus 2.x vers 3.0](/docs/migrate/from-2.x).
</Callout>

## Installer le playbook comme skill Claude Code

Téléchargez [nucleus-migrate.skill](https://nucleusframework.dev/nucleus-migrate.skill) et
décompressez-le dans votre répertoire de skills :

```shell
cd ~/.claude/skills && unzip ~/Downloads/nucleus-migrate.skill
```

Lancez `/nucleus-migrate`, ou demandez à Claude Code de migrer l'application vers Nucleus.

## Et ensuite

- [Migrer de Nucleus 2.x vers 3.0](/docs/migrate/from-2.x) : la liste que le premier prompt applique.
- [Migrer depuis JetBrains Compose Desktop](/docs/migrate/from-jb-compose) : la migration du build à la main.
