## Stabiliser les API de fenêtres d'outils

Les satellites, `DockLayout` et le workspace d'onglets sont `@ExperimentalNucleusApi` en 3.0, et
leur surface peut changer sans cycle de dépréciation. L'opt-in disparaîtra quand l'API tiendra sur
de vraies applications. Voir [Fenêtres d'outils](/docs/tool-windows).

## Limites connues

- **Modalité native des dialogues sous macOS et Linux.** Windows désactive la propriétaire d'un
  `DecoratedDialog` ; macOS et Linux ne bloquent que le pointeur dans la scène. Voir [Bloquer la
  propriétaire](/docs/windows/dialogs-popups#bloquer-la-propriétaire).
- **Scripts PAC sous Linux.** [`native-proxy`](/docs/performance/native-proxy) n'y applique que les
  règles statiques et les listes d'exclusion, et n'est pas encore relié aux clients
  [HTTP natif](/docs/performance/native-http).
- **Identifiant de fenêtre macOS pour la capture.** Tao n'expose pas le `CGWindowID` d'une
  fenêtre : la [capture](/docs/os/screen-capture#capturer-une-fenêtre) de votre propre fenêtre le
  cherche dans `windows()`.
- **Occultation sous Windows et Linux.** Une fenêtre recouverte ou masquée n'arrête de se rendre
  que sous macOS. Voir [Fenêtres au repos](/docs/performance/rendering#fenêtres-au-repos).

## En attente des projets en amont

- **Types de l'API de fenêtres v2 de Compose.** Nucleus livre une copie sans AWT dans
  `dev.nucleusframework.window.tao.v2`. Si JetBrains découple les types d'origine d'AWT, vous
  importerez ceux-là.
- **Pincement et rotation dans les gestes Compose.** Dans Compose 1.12, `detectTransformGestures`
  ne voit pas les événements `Scale`, et Compose n'a pas d'événement de rotation.
- **Mises à jour de Tao.** Les correctifs des versions de Tao postérieures à 0.35 sont reportés à
  la main dans Nucleus.

## À l'étude

Aucun engagement, aucune date. Ouvrez une issue si vous avez besoin de l'un d'eux :

| Module | Description |
| --- | --- |
| `clipboard` | Formats HTML et RTF du presse-papiers et surveillance des changements. Le texte, les images et les listes de fichiers fonctionnent déjà, voir [Linux et Wayland](/docs/windows/linux-wayland). |
| Enregistrement d'écran | Capture vidéo d'un écran ou d'une fenêtre. Les images fixes fonctionnent déjà, voir [Capture d'écran](/docs/os/screen-capture). |
| Événements de volumes | UUID de volume, classement interne, externe et réseau, et événements de montage, démontage et éjection dans `system-info` |
| Achats intégrés | Achats StoreKit 2 et Microsoft Store |

## Influencer l'ordre

Ouvrez une issue qui décrit votre cas d'usage, liez une application exemple qui a besoin du module,
ou financez l'implémentation pour une plateforme. Les modules les plus demandés sortent en premier.
