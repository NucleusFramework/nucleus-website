`system-color` lit la couleur d'accentuation et le réglage de contraste élevé de l'utilisateur
sous macOS, Windows et Linux. Les deux sont des composables qui recomposent quand l'utilisateur
les modifie dans les réglages du système.

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.system-color:<version>")
}
```

## Lire la couleur d'accentuation

```kotlin
import dev.nucleusframework.systemcolor.systemAccentColor

@Composable
fun App() {
    val accent = systemAccentColor()
    val scheme = if (accent != null) darkColorScheme(primary = accent) else darkColorScheme()

    MaterialTheme(colorScheme = scheme) {
        // Recomposes when the user picks another accent.
    }
}
```

`systemAccentColor()` renvoie `null` quand l'OS ne fournit pas de couleur d'accentuation, par
exemple sur un bureau Linux dont le portail n'a pas la clé `accent-color`. Revenez alors à la
couleur de votre marque.

## Lire le réglage de contraste élevé

```kotlin
val highContrast = isSystemInHighContrast()
// Strengthen borders and contrast tokens when highContrast is true.
```

<Accordion title="En coulisses">

- Le pont de chaque OS s'abonne aux notifications de changement du système ; rien n'interroge en
  boucle.
- Sous Linux, les valeurs viennent des clés `accent-color` et `contrast` de
  `org.freedesktop.portal.Settings`.

## Référence de l'API

| Fonction | Renvoie |
| --- | --- |
| `isSystemAccentColorSupported(): Boolean` | Si l'OS peut fournir une couleur d'accentuation. Non composable : appelable n'importe où |
| `@Composable systemAccentColor(): Color?` | La couleur d'accentuation courante, ou `null` |
| `@Composable isSystemInHighContrast(): Boolean` | Si l'OS est en mode contraste élevé |
