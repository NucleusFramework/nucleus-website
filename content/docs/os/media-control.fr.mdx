`media-control` publie les métadonnées d'une piste dans le centre média du système et reçoit les
commandes de lecture : À l'écoute sous macOS, les System Media Transport Controls (SMTC) sous
Windows et MPRIS sous Linux.

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.media-control:<version>")
}
```

## Publier les métadonnées de lecture

```kotlin
if (MediaControlService.isAvailable()) {
    MediaControlService.configure()
    MediaControlService.setMetadata(
        MediaMetadata(
            title = "Strobe",
            artist = "deadmau5",
            coverUrl = "file:///tmp/cover.png",
            duration = 10 * 60 * 1_000L,
        ),
    )
    MediaControlService.setPlaybackState(
        MediaPlaybackState(status = MediaPlaybackStatus.PLAYING, positionMs = 0),
    )
}
```

Publiez les métadonnées à chaque changement de piste, et un nouvel état à chaque lecture, pause,
arrêt et déplacement. Les durées s'expriment en millisecondes. Si la bibliothèque native ne se
charge pas, chaque appel reste sans effet.

## Traiter les commandes de lecture

```kotlin
MediaControlService.attach { event ->
    when (event) {
        MediaControlEvent.Play -> player.play()
        MediaControlEvent.Pause -> player.pause()
        MediaControlEvent.Next -> player.skipToNext()
        is MediaControlEvent.SetPosition -> player.seekTo(event.positionMs)
        else -> {}
    }
}
```

Le listener s'exécute sur le thread UI et peut modifier l'état Compose directement. Un second
`attach` remplace le premier listener. `detach()` retire l'application du centre média.

<Callout type="warn" title="Modifié en 3.0">
En 2.x, le listener d'`attach` s'exécutait sur l'EDT d'AWT. Il s'exécute désormais sur le thread
UI hôte (le thread principal Tao). Voir [Migrer depuis 2.x](/docs/migrate/from-2.x).
</Callout>

| Événement | Linux | macOS | Windows |
| --- | --- | --- | --- |
| `Play`, `Pause`, `Next`, `Previous`, `Stop`, `SetPosition` | oui | oui | oui |
| `Toggle` | oui | oui | non |
| `SeekBy` | oui | non | oui |
| `SetVolume`, `OpenUri`, `Raise`, `Quit` | oui | non | non |

## Notes par plateforme

- **macOS** : définissez `appCategory = "public.app-category.music"` sous
  `nucleus.application.nativeDistributions.macOS` pour que À l'écoute traite l'application comme
  un lecteur multimédia. Les touches média du clavier envoient alors Play, Pause, Next et Previous.
- **Windows** : testez avec l'application installée, car SMTC l'identifie par son raccourci du
  menu Démarrer. `coverUrl` accepte `file://`, un chemin nu ou `http(s)://`.
- **Linux** : le lecteur apparaît sous `org.mpris.MediaPlayer2.<suffix>`, dérivé de
  `NucleusApp.appId`, pour `playerctl` et les indicateurs du bureau. Une `coverUrl` locale doit
  utiliser `file://`. Si le bus de session est injoignable ou que `dbusName` est invalide,
  `attach` journalise un avertissement et rend la main, et `isAvailable()` renvoie toujours `true`.

<Accordions>
<Accordion title="En coulisses">

- macOS utilise `MPNowPlayingInfoCenter` et `MPRemoteCommandCenter` ; le bundle de l'application
  fournit l'identité.
- SMTC utilise l'AUMID que le plugin Nucleus appose sur le raccourci du menu Démarrer, ou
  l'identité du package MSIX. Il traite le dernier éditeur comme source courante.
- Sous Linux, `configure` enregistre le nom de bus MPRIS via D-Bus. Les caractères interdits de
  `appId` deviennent `_`, les éléments qui commencent par un chiffre reçoivent un préfixe `_`, les
  éléments vides disparaissent et le suffixe reste sous 255 caractères.

## Référence de l'API

| Symbole | Notes |
| --- | --- |
| `isAvailable()` | `true` si la bibliothèque native s'est chargée |
| `configure(dbusName, displayName)` | Tous deux facultatifs ; `displayName` vaut `NucleusApp.appName`, ou `"Nucleus App"` |
| `setMetadata(MediaMetadata)` | `title`, `artist`, `album`, `coverUrl`, `duration` ; chacun vaut `null` par défaut |
| `setPlaybackState(MediaPlaybackState)` | `status` (`STOPPED`, `PAUSED`, `PLAYING`), `positionMs` facultatif |
| `setVolume(value)` | Borné à `0.0..1.0`. macOS l'ignore |
| `attach(listener)` / `detach()` | Reçoit les `MediaControlEvent` / arrête et se désinscrit |
