`global-hotkey` enregistre des raccourcis clavier qui se déclenchent quelle que soit l'application
au premier plan, sous macOS, Windows et Linux.

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.global-hotkey:<version>")
}
```

## Enregistrer un raccourci

```kotlin
DisposableEffect(Unit) {
    GlobalHotKeyManager.initialize()
    val handle = GlobalHotKeyManager.register(
        keyCode = KeyEvent.VK_K,
        modifiers = HotKeyModifier.CONTROL + HotKeyModifier.SHIFT,
    ) { _, _ ->
        showQuickSwitcher()
    }
    onDispose { GlobalHotKeyManager.unregister(handle) }
}
```

- `register` renvoie un handle, ou `-1` si le système refuse la combinaison. `lastError` en donne
  la raison.
- `keyCode` prend les constantes de `java.awt.event.KeyEvent`. Le module ne démarre pas AWT.
- Le listener s'exécute sur le thread UI : il peut modifier l'état Compose directement. Un appui
  encore en file quand vous appelez `unregister` est ignoré.
- `GlobalHotKeyManager.register(MediaKey.PLAY_PAUSE) { … }` associe une touche multimédia sous
  Windows et Linux. Sous macOS, l'appel renvoie `-1` ; utilisez les
  [contrôles média](/docs/os/media-control).

## Enregistrements portail Linux

Sous Wayland, le portail du bureau demande à l'utilisateur d'approuver vos raccourcis, une fois
par combinaison. Nucleus regroupe les appels à `register` dans une seule boîte de dialogue, où
`description` sert de libellé à chaque raccourci. Appelez `commitRegistrations()` pour l'afficher
tout de suite et savoir si le portail a accepté l'ensemble.

Le portail exige un fichier `.desktop` en notation DNS inversée, et l'application doit démarrer
depuis ce fichier. Les compositeurs sans portail ne transmettent pas les raccourcis globaux.

<Callout type="warn" title="Autorisations macOS">
macOS peut demander à l'utilisateur d'autoriser votre application dans Réglages Système >
Confidentialité et sécurité > Surveillance de l'entrée, et parfois Accessibilité. Les callbacks
restent muets tant que l'utilisateur n'a pas accepté. Ouvrez ce panneau avec
`x-apple.systempreferences:com.apple.preference.security?Privacy_ListenEvent`.
</Callout>

<Accordions>
<Accordion title="En coulisses">

- Backends : `RegisterHotKey` sous Windows, Carbon `RegisterEventHotKey` sous macOS, `XGrabKey`
  sous X11, `org.freedesktop.portal.GlobalShortcuts` sous Wayland.
- Le portail mémorise chaque autorisation par paire `(app_id, shortcut_id)`. Nucleus dérive
  l'identifiant de la combinaison (`nucleus_m{mods}_k{keyCode}`), qui reste donc stable d'un
  lancement à l'autre. `portalShortcutId(handle)` le renvoie, ou `null` hors Linux.

</Accordion>

## Référence de l'API

| Symbole | Notes |
| --- | --- |
| `initialize()` | Charge la bibliothèque native et démarre la source d'événements |
| `register(keyCode, modifiers = 0, description = null, listener): Long` | Existe aussi en `register(MediaKey, listener)` : `PLAY_PAUSE`, `STOP`, `NEXT_TRACK`, `PREV_TRACK` |
| `HotKeyModifier.ALT` / `CONTROL` / `SHIFT` / `META` | Combinez avec `+`, `0 + META` pour un seul. Sous macOS, `ALT` est Option et `META` Commande ; ailleurs, `META` est la touche Windows ou Super |
| `commitRegistrations()` | Affiche tout de suite la boîte de dialogue du portail Wayland |
| `isAvailable` / `lastError` | Bibliothèque native chargée ; message du dernier échec, `null` après un succès |
| `unregister(handle): Boolean` / `shutdown()` | Libère une combinaison / toutes. Appelez `shutdown()` à la fermeture |
