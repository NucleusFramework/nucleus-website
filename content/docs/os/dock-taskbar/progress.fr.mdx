Taskbar progress affiche une barre de progression et demande l'attention sur l'icône du Dock
macOS, le bouton de la barre des tâches Windows ou l'entrée du launcher Linux. Si le bureau ne le
prend pas en charge, les appels renvoient `false` au lieu de lever une exception.

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.taskbar-progress-tao:<version>")
}
```

Un hôte Compose Desktop ou Swing classique utilise `taskbar-progress` seul. Voir
[Utiliser l'API de base](#utiliser-lapi-de-base).

## Afficher une progression depuis une fenêtre

```kotlin
DecoratedWindow(onCloseRequest = ::exitApplication) {
    val progress by download.progress.collectAsState()

    LaunchedEffect(progress) {
        if (progress < 1.0) nucleusWindow.showTaskbarProgress(progress)
        else nucleusWindow.hideTaskbarProgress()
    }
    DisposableEffect(Unit) {
        onDispose { nucleusWindow.hideTaskbarProgress() }
    }
}
```

La valeur est une fraction dans `0.0..1.0`. Effacez-la dans `onDispose` pour qu'une barre
obsolète ne survive pas à l'écran qui l'a posée. `showTaskbarIndeterminate()`,
`showTaskbarError()`, `showTaskbarPaused()`, `requestTaskbarAttention()` et
`stopTaskbarAttention()` s'utilisent de la même façon.

Sur macOS et Linux, la progression appartient à l'application, pas à la fenêtre : deux fenêtres
partagent le même indicateur.

Dans la composition, `rememberTaoTaskbarProgress()` renvoie un handle lié à la fenêtre courante
(`null` hors fenêtre) : `taskbar?.showProgress(progress)`.

## Utiliser l'API de base

`TaskbarProgress` prend une `java.awt.Window`, pour les hôtes Compose Desktop et Swing :

```kotlin
TaskbarProgress.showProgress(window, 0.75)
TaskbarProgress.showError(window, 1.0)
TaskbarProgress.hideProgress(window)
TaskbarProgress.requestAttention(window, TaskbarProgress.AttentionType.INFORMATIONAL)
```

<Callout type="warn" title="Modifié en 3.0">
Les fenêtres `nucleusApplication` n'ont pas de `Window` AWT. Passez ces appels sur les extensions
`nucleusWindow`. Voir [Migrer depuis la 2.x](/docs/migrate/from-2.x).
</Callout>

## Définir le fichier desktop Linux

Si la détection du fichier `.desktop` échoue, `isAvailable()` renvoie `false`. Indiquez le nom
vous-même :

```kotlin
TaskbarProgress.linuxDesktopFilename = "myapp.desktop"
```

## Référence de l'API

| Extension `nucleusWindow` | `TaskbarProgress` | Effet |
|---|---|---|
| `showTaskbarProgress(value)` | `showProgress(window, value)` | `NORMAL` à `value` |
| `showTaskbarIndeterminate()` | `showIndeterminate(window)` | `INDETERMINATE` |
| `showTaskbarError(value = 1.0)` | `showError(window, value)` | `ERROR` à `value` |
| `showTaskbarPaused(value = 1.0)` | `showPaused(window, value)` | `PAUSED` à `value` |
| `hideTaskbarProgress()` | `hideProgress(window)` | `NO_PROGRESS` |
| `setTaskbarProgress(value)` / `setTaskbarState(state)` | `setProgress` / `setState` | Fraction ou état seul |
| `requestTaskbarAttention(type)` / `stopTaskbarAttention()` | `requestAttention` / `stopAttention` | Lance ou annule l'attention |

`TaskbarProgress` expose aussi `isAvailable()`, `linuxDesktopFilename` et des variantes
`*ForHwnd` pour un `HWND` Windows brut.

| État | Windows | macOS | Linux |
|---|---|---|---|
| `INDETERMINATE` | Barre animée | Barre fixe | Comme `NORMAL` |
| `NORMAL` | Vert | Bleu | Accent |
| `ERROR` | Rouge | Rouge | Progression simple ; ajoutez `requestAttention` |
| `PAUSED` | Jaune | Jaune | Progression simple |

| `AttentionType` | Windows | macOS |
|---|---|---|
| `INFORMATIONAL` | Clignote quatre fois | Rebondit une fois |
| `CRITICAL` | Clignote jusqu'au focus | Rebondit jusqu'à l'activation |

Sur Linux, les deux posent le flag `urgent`.
