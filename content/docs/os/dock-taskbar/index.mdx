title: Dock and taskbar
description: Progress, badges and menus on the macOS Dock, the Windows taskbar and the Linux launcher.
---

Each OS gives your app an icon outside its windows: the Dock on macOS, the taskbar button on
Windows, the launcher entry on Linux. Nucleus lets you draw on it and add menus to it.

| You want to | macOS | Windows | Linux |
| --- | --- | --- | --- |
| Show progress or request attention | [Progress](/docs/os/dock-taskbar/progress) | [Progress](/docs/os/dock-taskbar/progress) | [Progress](/docs/os/dock-taskbar/progress) |
| Add items to the icon's right-click menu | [Dock menu](/docs/os/dock-taskbar/macos) | [Jump list](/docs/os/dock-taskbar/windows#build-a-jump-list) | [Quicklist](/docs/os/dock-taskbar/linux#add-a-quicklist-menu) |
| Show a badge | [Dock badge](/docs/os/notifications/macos) | [Badge](/docs/os/dock-taskbar/windows#show-a-badge) | [Count badge](/docs/os/dock-taskbar/linux#set-badges-and-progress) |
| Add an overlay icon or toolbar buttons | none | [Overlay and buttons](/docs/os/dock-taskbar/windows) | none |

Start with [Progress and attention](/docs/os/dock-taskbar/progress): one API covers all three
systems. The per-OS pages add what only that system has.

## What's next

- [Progress and attention](/docs/os/dock-taskbar/progress): the cross-platform API.
- [System tray](/docs/os/tray): an icon in the menu bar or notification area instead.
- [Notifications](/docs/os/notifications): messages that reach the user outside the window.
