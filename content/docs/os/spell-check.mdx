`spellcheck` checks spelling with the engine each operating system ships, underlines misspelled
words in a Compose text field and adds suggestions to its context menu. It comes with
`nucleus-application`; declare `dev.nucleusframework:nucleus.spellcheck` alone to use the engine
without Compose.

## Check a text field

Wrap the field in `SpellcheckContextMenu`:

```kotlin
import dev.nucleusframework.application.spellcheck.SpellcheckContextMenu

@Composable
fun NoteField(value: String, onValueChange: (String) -> Unit) {
    SpellcheckContextMenu(text = value, onTextChange = onValueChange) {
        BasicTextField(value = value, onValueChange = onValueChange, singleLine = true)
    }
}
```

Misspelled words get a red wavy underline. A right click lists suggestions and Add to dictionary
next to Cut, Copy and Paste. Picking a suggestion calls `onTextChange` with the new text. An
overload takes a `TextFieldState` and edits it for you:
`SpellcheckContextMenu(state = state) { TextField(state = state) }`.

The wrapper works with `BasicTextField`, Material `TextField` and Jewel `TextField`, and keeps the
menu renderer you installed, such as the [native context menu](/docs/os/menus/context-menu) or
Jewel's.

## Choose the check language

The wrapper checks in `SpellChecker.locale`, which starts as `Locale.getDefault()`. Pass `locale`
to check one field in another language, or `session` to supply your own `SpellcheckSession` (it
wins over `locale`).

To switch the whole app, assign `SpellChecker.locale`. Loading a dictionary reads from disk, so
warm the session off the UI thread:

```kotlin
LaunchedEffect(locale) {
    SpellChecker.locale = locale
    withContext(Dispatchers.IO) { SpellChecker.ensureSession(locale) }
}
```

`SpellChecker.session` blocks on first access while the dictionary loads. On a frame path, read
`sessionIfReady` instead.

## Place the menu items

`menuPlacement = SpellcheckMenuPlacement.Top` puts the suggestions above Cut, Copy, Paste and your
app items. The default, `Bottom`, puts them below. A separator appears when the menu renderer
publishes one, as the native context menu and Jewel do.

## Platform notes

- **Linux**: your users need the distribution's Hunspell library and a dictionary package
  (`<tag>.aff` and `<tag>.dic`).
  Nucleus searches `$DICPATH` (colon-separated) before the system folders.
- **macOS** and **Windows**: you ship no dictionary files. The languages come from the system
  and, on Windows, the language packs the user installed.
- With no engine or dictionary, nothing throws: `check` and `addToDictionary` return `false`,
  `suggest` returns an empty list, and `SpellcheckContextMenu` renders its content unchanged.

  Jewel menu styling.

## API reference

Compose, in `dev.nucleusframework.application.spellcheck`:

| Symbol | Description |
| --- | --- |
| `SpellcheckContextMenu(text, onTextChange, session?, locale?, menuPlacement, content)` | Underlines misspellings and adds suggestions to the field's menu |
| `SpellcheckContextMenu(state, session?, locale?, menuPlacement, content)` | Same, for a `TextFieldState` |
| `NucleusSpellcheckInstaller.menuItems(word, session, onSuggestion, onAddToDictionary, separator?, menuPlacement)` | Suggestion items for a menu you assemble |
| `drawMisspellingSquiggles(drawScope, layout, ranges, color)` | Wavy underline for a custom text renderer |

Engine, in `dev.nucleusframework.spellcheck`:

| Symbol | Description |
| --- | --- |
| `SpellChecker` | Process-wide: `locale`, `session`, `sessionIfReady`, `isAvailable`, `ensureSession()`, `check()`, `suggest()`, `addToDictionary()`, `misspellings()` |
| `SpellcheckSession(locale, osName, dictionaryDirectories, userDictionaryFile)` | One dictionary, `AutoCloseable`. `defaultUserDictionaryFile(locale)` gives the user file path |
| `DictionaryLocator.defaultDirectories()` / `find(locale, directories)` | Hunspell search path / matching `DictionaryFiles(aff, dic, tag)` |
| `iterateWords`, `misspellingRanges`, `wordAt`, `replaceWord` | Tokenize text (`SpellcheckWord(start, end, word)`) and edit one token |
| `buildSpellcheckMenuModel(word, session, range?, maxSuggestions)`, `applySuggestion(text, model, suggestion)` | Suggestions plus the localized Add to dictionary label, and the edit they produce |
