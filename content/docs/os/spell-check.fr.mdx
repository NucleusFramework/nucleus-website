`spellcheck` vérifie l'orthographe avec le moteur livré par chaque système, souligne les mots mal
orthographiés d'un champ de texte Compose et ajoute des suggestions à son menu contextuel. Le
module est fourni avec `nucleus-application` ; déclarez `dev.nucleusframework:nucleus.spellcheck`
seul pour utiliser le moteur sans Compose.

## Vérifier un champ de texte

Enveloppez le champ dans `SpellcheckContextMenu` :

```kotlin
import dev.nucleusframework.application.spellcheck.SpellcheckContextMenu

@Composable
fun NoteField(value: String, onValueChange: (String) -> Unit) {
    SpellcheckContextMenu(text = value, onTextChange = onValueChange) {
        BasicTextField(value = value, onValueChange = onValueChange, singleLine = true)
    }
}
```

Les mots mal orthographiés reçoivent un soulignement ondulé rouge. Un clic droit affiche les
suggestions et Ajouter au dictionnaire à côté de Couper, Copier et Coller. Choisir une suggestion
appelle `onTextChange` avec le nouveau texte. Une surcharge prend un `TextFieldState` et le
modifie pour vous : `SpellcheckContextMenu(state = state) { TextField(state = state) }`.

Le wrapper fonctionne avec `BasicTextField`, le `TextField` Material et le `TextField` Jewel, et
conserve le moteur de rendu de menu que vous avez installé, comme le
[menu contextuel natif](/docs/os/menus/context-menu) ou celui de Jewel.

## Choisir la langue de vérification

Le wrapper vérifie dans `SpellChecker.locale`, qui vaut au départ `Locale.getDefault()`. Passez
`locale` pour vérifier un champ dans une autre langue, ou `session` pour fournir votre propre
`SpellcheckSession` (elle l'emporte sur `locale`).

Pour changer toute l'application, affectez `SpellChecker.locale`. Charger un dictionnaire lit le
disque : préparez la session hors du thread UI.

```kotlin
LaunchedEffect(locale) {
    SpellChecker.locale = locale
    withContext(Dispatchers.IO) { SpellChecker.ensureSession(locale) }
}
```

`SpellChecker.session` bloque au premier accès pendant le chargement du dictionnaire. Sur un
chemin de rendu, lisez plutôt `sessionIfReady`.

## Placer les entrées du menu

`menuPlacement = SpellcheckMenuPlacement.Top` place les suggestions au-dessus de Couper, Copier,
Coller et des entrées de votre application. La valeur par défaut, `Bottom`, les place en dessous.
Un séparateur apparaît quand le moteur de rendu du menu en publie un, comme le font le menu
contextuel natif et Jewel.

## Notes par plateforme

- **Linux** : vos utilisateurs ont besoin de la bibliothèque Hunspell de leur distribution et
  d'un paquet de dictionnaires (`<tag>.aff` et `<tag>.dic`). Nucleus cherche dans `$DICPATH`
  (séparé par des deux-points) avant les dossiers système.
- **macOS** et **Windows** : vous ne livrez aucun fichier de dictionnaire. Les langues viennent du
  système et, sous Windows, des modules linguistiques installés par l'utilisateur.
- Sans moteur ni dictionnaire, rien ne lève d'exception : `check` et `addToDictionary` renvoient
  `false`, `suggest` renvoie une liste vide et `SpellcheckContextMenu` affiche son contenu tel
  quel.

## Référence de l'API

Compose, dans `dev.nucleusframework.application.spellcheck` :

| Symbole | Description |
| --- | --- |
| `SpellcheckContextMenu(text, onTextChange, session?, locale?, menuPlacement, content)` | Souligne les fautes et ajoute les suggestions au menu du champ |
| `SpellcheckContextMenu(state, session?, locale?, menuPlacement, content)` | Idem, pour un `TextFieldState` |
| `NucleusSpellcheckInstaller.menuItems(word, session, onSuggestion, onAddToDictionary, separator?, menuPlacement)` | Les entrées de suggestion, pour un menu que vous assemblez |
| `drawMisspellingSquiggles(drawScope, layout, ranges, color)` | Soulignement ondulé pour un rendu de texte personnalisé |

Moteur, dans `dev.nucleusframework.spellcheck` :

| Symbole | Description |
| --- | --- |
| `SpellChecker` | Singleton du processus : `locale`, `session`, `sessionIfReady`, `isAvailable`, `ensureSession()`, `check()`, `suggest()`, `addToDictionary()`, `misspellings()` |
| `SpellcheckSession(locale, osName, dictionaryDirectories, userDictionaryFile)` | Un dictionnaire, `AutoCloseable`. `defaultUserDictionaryFile(locale)` donne le chemin du fichier utilisateur |
| `DictionaryLocator.defaultDirectories()` / `find(locale, directories)` | Chemin de recherche Hunspell / `DictionaryFiles(aff, dic, tag)` correspondant |
| `iterateWords`, `misspellingRanges`, `wordAt`, `replaceWord` | Découpent le texte (`SpellcheckWord(start, end, word)`) et remplacent un mot |
| `buildSpellcheckMenuModel(word, session, range?, maxSuggestions)`, `applySuggestion(text, model, suggestion)` | Suggestions avec le libellé localisé Ajouter au dictionnaire, et la modification qui en résulte |
