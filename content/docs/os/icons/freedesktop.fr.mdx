---
title: Icônes FreeDesktop
description: Constantes Kotlin typées pour les noms définis par la FreeDesktop Icon Naming Specification.
---

`freedesktop-icons` fournit les noms de la
[FreeDesktop Icon Naming Specification](https://specifications.freedesktop.org/icon-naming/latest/)
sous forme de constantes Kotlin typées. Vous envoyez `dialog-information` au lieu de livrer
`info.png`, et le thème d'icônes Linux de l'utilisateur dessine sa propre version.

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.freedesktop-icons:<version>")
}
```

`notification-linux` et `launcher-linux` l'apportent déjà.

## Référencer une icône

Choisissez la constante dans l'enum de catégorie qui correspond à son contexte :

```kotlin
val info = FreedesktopIcon.Status.DIALOG_INFORMATION
val printer = FreedesktopIcon.Device.PRINTER

// A name outside the specification, an absolute path, or a file:// URI
val named = FreedesktopIcon.Custom("my-app-icon")
val path = FreedesktopIcon.Custom("/home/user/icon.png")

// Country flag from an ISO 3166-1 alpha-2 code
val flag = FreedesktopIcon.flag("FR") // Custom("flag-fr")
```

- Les thèmes n'implémentent pas tous les noms. Ceux de la spécification de base ont le plus de
  chances d'être trouvés.
- Les noms de drapeaux ne font pas partie de la spécification. Ils ne se résolvent que dans les
  thèmes qui livrent des icônes `flag-<code>`.
- Le module compile sur tous les OS, mais aucun thème ne résout les noms hors de Linux.

## Référence de l'API

| Catégorie | Exemples |
| --- | --- |
| `FreedesktopIcon.Action` | `DOCUMENT_OPEN`, `EDIT_COPY`, `MEDIA_PLAYBACK_START` |
| `FreedesktopIcon.Animation` | `PROCESS_WORKING` |
| `FreedesktopIcon.Application` | `ACCESSORIES_TEXT_EDITOR`, `MULTIMEDIA_VOLUME_CONTROL`, `UTILITIES_TERMINAL` |
| `FreedesktopIcon.Category` | `APPLICATIONS_INTERNET`, `PREFERENCES_DESKTOP`, `SYSTEM_HELP` |
| `FreedesktopIcon.Device` | `PRINTER`, `CAMERA_PHOTO`, `INPUT_KEYBOARD` |
| `FreedesktopIcon.Emblem` | `IMPORTANT`, `FAVORITE`, `SHARED` |
| `FreedesktopIcon.Emote` | `FACE_SMILE`, `FACE_SAD`, `FACE_WINK` |
| `FreedesktopIcon.MimeType` | `TEXT_X_GENERIC`, `IMAGE_X_GENERIC`, `X_OFFICE_DOCUMENT` |
| `FreedesktopIcon.Place` | `FOLDER`, `USER_HOME`, `NETWORK_SERVER` |
| `FreedesktopIcon.Status` | `DIALOG_INFORMATION`, `DIALOG_WARNING`, `BATTERY_LOW` |
| `FreedesktopIcon.Custom(value)` | Value class inline, transmise telle quelle : nom de thème, chemin absolu ou URI `file://` |
| `FreedesktopIcon.flag(countryCode)` | Met le code en minuscules et renvoie `Custom("flag-<code>")` |

Chaque constante contient son nom de spécification dans `value`.
