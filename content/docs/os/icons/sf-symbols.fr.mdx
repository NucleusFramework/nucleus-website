`sf-symbols` fournit les noms [SF Symbols](https://developer.apple.com/sf-symbols/) d'Apple sous
forme de constantes Kotlin typées. Vous écrivez `SFSymbolObjectsAndTools.SCISSORS` au lieu de
`"scissors"`, et le compilateur détecte les fautes de frappe.

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.sf-symbols:<version>")
}
```

[`menu-macos`](/docs/os/menus/menu-bar) l'apporte déjà.

## Référencer un symbole

Choisissez la constante dans l'enum de catégorie qui correspond à son usage, et passez-la à une
API macOS qui prend un symbole :

```kotlin
val icon = NsMenuItemImage.SystemSymbol(SFSymbolObjectsAndTools.SCISSORS)

// A name the constants do not cover, such as one from a newer SF Symbols release
val custom = SFSymbol.Custom("bird.fill")
```

Les symboles numériques prennent un préfixe `_`, car un identifiant Kotlin ne peut pas commencer
par un chiffre : `SFSymbolNumbers._0_CIRCLE` correspond à `"0.circle"`. Les SF Symbols exigent
macOS 11 ou plus ; le module compile et se charge quand même sur tous les OS.

<Accordions>
<Accordion title="En coulisses">

- Chaque constante porte son nom dans `symbolName` (`GEAR` contient `"gear"`). `Custom` est une
  value class inline qui enveloppe n'importe quelle chaîne, transmise telle quelle.
- AppKit résout le nom avec `imageWithSystemSymbolName:accessibilityDescription:` au rendu : le
  glyphe suit l'apparence du système et vous ne livrez aucune image.

</Accordion>
</Accordions>

## Référence de l'API

`SFSymbol` est une interface scellée avec 21 enums de catégorie, plus `Custom(symbolName)` :

| Catégorie | Exemples |
| --- | --- |
| `SFSymbolGeneral` | `GEAR`, `GEARSHAPE` |
| `SFSymbolHuman` | `ACCESSIBILITY`, `BRAIN` |
| `SFSymbolShapes` | `APP`, `APP_BADGE` |
| `SFSymbolArrows` | `ARROW_LEFT`, `ARROW_CLOCKWISE` |
| `SFSymbolTransportation` | `AIRPLANE`, `AIRPLANE_ARRIVAL` |
| `SFSymbolObjectsAndTools` | `SCISSORS`, `FOLDER`, `TRASH` |
| `SFSymbolDevices` | `DESKTOPCOMPUTER`, `KEYBOARD` |
| `SFSymbolNumbers` | `_0_CIRCLE`, `_0_CIRCLE_FILL` |
| `SFSymbolWeather` | `CLOUD`, `SUN_MAX`, `BOLT` |
| `SFSymbolStatus` | `CHECKMARK`, `INFO_CIRCLE` |
| `SFSymbolCommerce` | `BAG`, `BAG_BADGE_PLUS` |
| `SFSymbolMedia` | `PLAY`, `PAUSE`, `STOP` |
| `SFSymbolLetters` | `A_CIRCLE`, `A_SQUARE` |
| `SFSymbolTextFormatting` | `BOLD`, `CHARACTER` |
| `SFSymbolCommunication` | `ENVELOPE`, `PHONE`, `MESSAGE` |
| `SFSymbolPower` | `POWER`, `POWER_CIRCLE` |
| `SFSymbolSecurity` | `KEY`, `KEY_FILL` |
| `SFSymbolHealth` | `ALLERGENS`, `BASEBALL` |
| `SFSymbolLocation` | `FLAG`, `COMPASS_DRAWING` |
| `SFSymbolTime` | `ALARM`, `ALARM_FILL` |
| `SFSymbolConnectivity` | `CABLE_COAXIAL`, `CABLE_CONNECTOR` |
