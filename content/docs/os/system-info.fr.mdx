title: Infos système

---

`SystemInfo` lit les détails de la machine sous macOS, Windows et Linux : système
d'exploitation, CPU, mémoire, disques, GPU, batteries, interfaces réseau, processus et
utilisateurs.

## Ajouter la dépendance

```kotlin title="build.gradle.kts"
dependencies {
    implementation("dev.nucleusframework:nucleus.system-info:<version>")
}
```

## Lire la machine

```kotlin
import dev.nucleusframework.systeminfo.SystemInfo

val os = SystemInfo.osInfo() ?: return
println("OS: ${os.longOsVersion} (${os.cpuArch})")

SystemInfo.memoryInfo()?.let { mem ->
    println("Memory: ${mem.usedMemory / 1_048_576} MB of ${mem.totalMemory / 1_048_576} MB")
}

SystemInfo.batteryInfo()?.let { battery ->
    println("Battery: ${(battery.stateOfCharge * 100).toInt()}% (${battery.state})")
}
```

- Chaque appel lit les valeurs courantes et rend la main ; rien n'interroge ni ne met en cache en
  arrière-plan. Pour rafraîchir un affichage, rappelez la méthode à votre rythme, hors du thread
  UI pour les plus coûteuses.
- Une valeur que la machine ne peut pas fournir revient en `null` (valeurs simples) ou en liste
  vide. Aucun appel ne lève d'exception.
- La couverture varie selon l'OS. Windows expose peu de capteurs de température via
  `components()`, et `motherboard()` renvoie le plus de champs sous Linux.
- `processes()` parcourt toute la table des processus. Appelez `process(pid)` pour une seule
  entrée.

## Référence de l'API

| Méthode | Renvoie |
| --- | --- |
| `isAvailable()` | Si la bibliothèque native s'est chargée sur cet OS |
| `osInfo()` | `OsInfo?` : `name`, `osVersion`, `longOsVersion`, `kernelVersion`, `distributionId`, `hostName`, `cpuArch`, `uptime`, `bootTime` |
| `cpuInfo()` | `CpuGlobalInfo?` : `globalCpuUsage`, `physicalCoreCount`, `cpus` (un `CpuInfo` par cœur logique : `name`, `vendorId`, `brand`, `frequency`, `cpuUsage`) |
| `memoryInfo()` | `MemoryInfo?` : `totalMemory`, `freeMemory`, `availableMemory`, `usedMemory`, `totalSwap`, `freeSwap`, `usedSwap`, en octets |
| `disks()` | `List<DiskInfo>` : `name`, `fileSystem`, `mountPoint`, `totalSpace`, `availableSpace`, `kind`, `isRemovable`, `isReadOnly` |
| `gpus()` | `List<GpuInfo>` : nom, identifiants fabricant et appareil, mémoire vidéo et, quand le pilote les fournit, `driverVersion`, `temperature`, `gpuUsage`, fréquences, vitesse du ventilateur, consommation |
| `batteryInfo()` | `BatteryInfo?` : `stateOfCharge` (`0.0..1.0`), `state` (`Charging`, `Discharging`, `Full`, `Unknown`), `isPluggedIn`, capacités, `cycleCount`, `health`, estimations de durée, identité de l'appareil. `null` sans batterie |
| `networks()` | `List<NetworkInterfaceInfo>` |
| `connectivityInfo()` | `ConnectivityInfo?` : `isConnected`, `meteredStatus` (`NOT_AVAILABLE`, `UNKNOWN`, `UNMETERED`, `METERED`) |
| `processes()` / `process(pid: Long)` | `List<ProcessInfo>` / `ProcessInfo?` |
| `users()` | `List<UserInfo>` |
| `components()` | `List<ComponentInfo>` : capteurs de température |
| `motherboard()` / `product()` | `MotherboardInfo?` / `ProductInfo?` |
| `idleTime()` | Secondes depuis la dernière saisie, ou `-1` si la bibliothèque native ne s'est pas chargée |
