---
title: Trusted CA certificates
description: Import private root CA certificates into the Java runtime bundled with your packaged app so its HTTPS calls trust them.
---

`nativeDistributions.trustedCertificates` imports CA certificates into the Java runtime your app
ships with. Use it when your users sit behind a corporate proxy, a ZTNA gateway, or a filter that
terminates TLS with a private root CA. Without that CA, HTTPS calls fail with
`SSLHandshakeException`.

## Declare the certificates

```kotlin title="build.gradle.kts"
nucleus.application {
    nativeDistributions {
        trustedCertificates.from(
            files(
                "certs/company-ca.pem",
                "certs/vpn-root.crt",
            ),
        )
    }
}
```

The plugin accepts PEM and DER files, and packaging imports them for you. Only the bundled runtime
changes: the user's system, the user's JDK and the build JDK stay untouched.

`trustedCertificates` covers CAs you know at build time. To also trust CAs the user installed in
the OS store, add [`native-ssl`](/docs/performance/native-ssl).

## API reference

| Symbol | Type | Description |
| --- | --- | --- |
| `nativeDistributions.trustedCertificates` | `ConfigurableFileCollection` | PEM or DER files to import into the bundled runtime's `cacerts`. |
| `patchCaCertificates` | Gradle task | Imports the certificates into a copy of the runtime image. Exists only when `trustedCertificates` is non-empty. |
