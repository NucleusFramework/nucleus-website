This page covers the `linux { }` block: DEB, RPM, AppImage, Pacman, Snap, and Flatpak. Linux
formats build only on a Linux host with `rpm` and `fakeroot` (RPM), `libfuse2` (AppImage), and
`flatpak` plus `flatpak-builder` (Flatpak). The `setup-nucleus` CI action installs them.

## Configure the target formats

```kotlin title="build.gradle.kts"
nativeDistributions {
    targetFormats(TargetFormat.Deb, TargetFormat.Rpm, TargetFormat.AppImage, TargetFormat.Pacman)
    homepage = "https://myapp.example.com" // required by DEB and RPM

    linux {
        iconFile.set(project.file("icons/app.png"))
        packageName = "myapp"
        appCategory = "Utility"
        debMaintainer = "Your Name <dev@example.com>"
        debDepends = listOf("libgtk-3-0", "libasound2")
        rpmRequires = listOf("gtk3", "alsa-lib")
        pacmanDepends = listOf("gtk3", "alsa-lib")
    }
}
```

Build with `packageDeb`, `packageRpm`, or `packagePacman`. The `StartupWMClass` of the `.desktop`
entry defaults to `mainClass` with dots replaced by hyphens; set `startupWMClass` if the window
manager reports another class. Bump `appRelease` to re-release the same `packageVersion`.

## Build an AppImage

An AppImage is one executable that runs on most distributions without installation. Build it with
`packageAppImage`.

```kotlin title="build.gradle.kts"
linux {
    appImage {
        category = AppImageCategory.Utility
        genericName = "My Application"
        compressionLevel = CompressionLevel.Normal
    }
}
```

`Maximum` and `Ultra` compression slow every AppImage launch, so keep `Normal` for the AppImage
even when `nativeDistributions.compressionLevel` is higher. `Ultra` also recompresses the DEB.

## Add install and remove scripts

DEB, RPM, and Pacman run maintainer scripts as root. AppImage, Snap, and Flatpak do not.

```kotlin title="build.gradle.kts"
linux {
    afterInstall.set(project.file("packaging/linux/after-install.sh"))
    afterRemove.set(project.file("packaging/linux/after-remove.sh"))
    beforeInstall.set(project.file("packaging/linux/before-install.sh"))
    beforeRemove.set(project.file("packaging/linux/before-remove.sh"))
    // Pacman only: an upgrade runs these instead of the install and remove scripts
    afterUpgrade.set(project.file("packaging/linux/after-upgrade.sh"))
    beforeUpgrade.set(project.file("packaging/linux/before-upgrade.sh"))
}
```

The payload lives under `/opt/<packageName>`, a path with no spaces. To ship a systemd unit, enable
it in `afterInstall`, stop it in `beforeInstall`, and disable it in `afterRemove`.

In `afterInstall` and `afterRemove`, `${executable}` and `${sanitizedProductName}` expand only
inside single quotes. A double-quoted `"${executable}"` stays literal and fails silently. The other
four scripts get no substitution: write names out in full.

```shell title="packaging/linux/after-install.sh"
systemctl enable '${executable}-daemon.service'
```

<Callout type="warn">
A Pacman upgrade runs only `beforeUpgrade` and `afterUpgrade`. Stop the service in the first and
restart it in the second, or the upgrade leaves it stopped. DEB and RPM ignore the upgrade
properties.
</Callout>

## Publish to the Snap Store

```kotlin title="build.gradle.kts"
linux {
    snap {
        confinement = SnapConfinement.Strict
        base = "core22"
        plugs = listOf(SnapPlug.Desktop, SnapPlug.Home, SnapPlug.Wayland, SnapPlug.Network)
    }
}
```

Build with `packageSnap`; the host needs no `snapcraft`. Setting `plugs` replaces the default list.
Snap packaging skips arm64 hosts.

## Publish to Flathub with Flatpak

```kotlin title="build.gradle.kts"
linux {
    flatpak {
        runtime = "org.freedesktop.Platform"
        runtimeVersion = "23.08"
        sdk = "org.freedesktop.Sdk"
        finishArgs = listOf("--share=ipc", "--socket=wayland", "--device=dri", "--share=network")
    }
}
```

Build with `packageFlatpak`. `finishArgs` declares the sandbox permissions and replaces the
defaults (`--share=ipc`, `--socket=x11`, `--socket=wayland`, `--socket=pulseaudio`,
`--device=dri`). Without `flatpak` on the host, the task skips the format.

## Register deep links and file associations

The plugin adds `protocol(...)` and `fileAssociation(...)` to the `.desktop` file's `MimeType=`:

```kotlin title="build.gradle.kts"
nativeDistributions {
    protocol("MyApp URL", "myapp")
    fileAssociation(mimeType = "application/x-myapp", extension = "myapp", description = "MyApp Document")
}
```

<Accordion title="Under the hood">

- `afterInstall` and `afterRemove` are appended to Nucleus's template (desktop integration,
  AppArmor, polkit policy for passwordless updates). The other four go raw to fpm.
- `Ultra` rebuilds the DEB with `xz -9e`. RPM and Pacman already use xz.
- electron-builder builds the snap from its own template, which has no arm64 build.
