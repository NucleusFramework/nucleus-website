Cette page couvre le bloc `linux { }` : DEB, RPM, AppImage, Pacman, Snap et Flatpak. Les formats
Linux se construisent uniquement sur un hôte Linux avec `rpm` et `fakeroot` (RPM), `libfuse2`
(AppImage), et `flatpak` plus `flatpak-builder` (Flatpak). L'action CI `setup-nucleus` les
installe.

## Configurer les formats cibles

```kotlin title="build.gradle.kts"
nativeDistributions {
    targetFormats(TargetFormat.Deb, TargetFormat.Rpm, TargetFormat.AppImage, TargetFormat.Pacman)
    homepage = "https://myapp.example.com" // exigé par DEB et RPM

    linux {
        iconFile.set(project.file("icons/app.png"))
        packageName = "myapp"
        appCategory = "Utility"
        debMaintainer = "Your Name <dev@example.com>"
        debDepends = listOf("libgtk-3-0", "libasound2")
        rpmRequires = listOf("gtk3", "alsa-lib")
        pacmanDepends = listOf("gtk3", "alsa-lib")
    }
}
```

Construisez avec `packageDeb`, `packageRpm` ou `packagePacman`. Le `StartupWMClass` de l'entrée
`.desktop` vaut par défaut `mainClass` avec les points remplacés par des tirets ; réglez
`startupWMClass` si le gestionnaire de fenêtres signale une autre classe. Incrémentez `appRelease`
pour republier le même `packageVersion`.

## Construire un AppImage

Un AppImage est un exécutable unique qui tourne sur la plupart des distributions sans
installation. Construisez-le avec `packageAppImage`.

```kotlin title="build.gradle.kts"
linux {
    appImage {
        category = AppImageCategory.Utility
        genericName = "My Application"
        compressionLevel = CompressionLevel.Normal
    }
}
```

Les compressions `Maximum` et `Ultra` ralentissent chaque lancement de l'AppImage : gardez `Normal`
pour l'AppImage même quand `nativeDistributions.compressionLevel` est plus élevé. `Ultra`
recompresse aussi le DEB.

## Ajouter des scripts d'installation et de désinstallation

DEB, RPM et Pacman exécutent les scripts de maintenance en root. AppImage, Snap et Flatpak ne les
exécutent pas.

```kotlin title="build.gradle.kts"
linux {
    afterInstall.set(project.file("packaging/linux/after-install.sh"))
    afterRemove.set(project.file("packaging/linux/after-remove.sh"))
    beforeInstall.set(project.file("packaging/linux/before-install.sh"))
    beforeRemove.set(project.file("packaging/linux/before-remove.sh"))
    // Pacman uniquement : une mise à niveau exécute ceux-ci à la place des scripts d'installation
    afterUpgrade.set(project.file("packaging/linux/after-upgrade.sh"))
    beforeUpgrade.set(project.file("packaging/linux/before-upgrade.sh"))
}
```

Le contenu est installé sous `/opt/<packageName>`, un chemin sans espaces. Pour livrer une unité
systemd, activez-la dans `afterInstall`, arrêtez-la dans `beforeInstall` et désactivez-la dans
`afterRemove`.

Dans `afterInstall` et `afterRemove`, `${executable}` et `${sanitizedProductName}` ne sont
remplacés qu'entre apostrophes. Un `"${executable}"` entre guillemets doubles reste littéral et
échoue sans erreur. Les quatre autres scripts ne reçoivent aucune substitution : écrivez les noms
en entier.

```shell title="packaging/linux/after-install.sh"
systemctl enable '${executable}-daemon.service'
```

<Callout type="warn">
Une mise à niveau Pacman n'exécute que `beforeUpgrade` et `afterUpgrade`. Arrêtez le service dans
le premier et redémarrez-le dans le second, sinon la mise à niveau le laisse arrêté. DEB et RPM
ignorent les propriétés de mise à niveau.
</Callout>

## Publier sur le Snap Store

```kotlin title="build.gradle.kts"
linux {
    snap {
        confinement = SnapConfinement.Strict
        base = "core22"
        plugs = listOf(SnapPlug.Desktop, SnapPlug.Home, SnapPlug.Wayland, SnapPlug.Network)
    }
}
```

Construisez avec `packageSnap` ; l'hôte n'a pas besoin de `snapcraft`. Définir `plugs` remplace la
liste par défaut. L'empaquetage Snap est ignoré sur les hôtes arm64.

## Publier sur Flathub avec Flatpak

```kotlin title="build.gradle.kts"
linux {
    flatpak {
        runtime = "org.freedesktop.Platform"
        runtimeVersion = "23.08"
        sdk = "org.freedesktop.Sdk"
        finishArgs = listOf("--share=ipc", "--socket=wayland", "--device=dri", "--share=network")
    }
}
```

Construisez avec `packageFlatpak`. `finishArgs` déclare les permissions du sandbox et remplace les
valeurs par défaut (`--share=ipc`, `--socket=x11`, `--socket=wayland`, `--socket=pulseaudio`,
`--device=dri`). Sans `flatpak` sur l'hôte, la tâche ignore le format.

## Enregistrer les deep links et les associations de fichiers

Le plugin ajoute `protocol(...)` et `fileAssociation(...)` à la ligne `MimeType=` du fichier
`.desktop` :

```kotlin title="build.gradle.kts"
nativeDistributions {
    protocol("MyApp URL", "myapp")
    fileAssociation(mimeType = "application/x-myapp", extension = "myapp", description = "MyApp Document")
}
```

- `afterInstall` et `afterRemove` sont ajoutés au modèle de Nucleus (intégration au bureau,

- `Ultra` reconstruit le DEB avec `xz -9e`. RPM et Pacman utilisent déjà xz.
- electron-builder construit le snap à partir de son propre modèle, qui n'existe pas pour arm64.
