---
title: Certificats d'autorité de confiance
description: Importez des certificats racines privés dans le runtime Java livré avec votre application pour que ses appels HTTPS leur fassent confiance.
---

`nativeDistributions.trustedCertificates` importe des certificats d'autorité dans le runtime Java
livré avec votre application. Utilisez-le quand vos utilisateurs passent par un proxy d'entreprise,
une passerelle ZTNA ou un filtre qui termine le TLS avec une autorité racine privée. Sans cette
autorité, les appels HTTPS échouent avec `SSLHandshakeException`.

## Déclarer les certificats

```kotlin title="build.gradle.kts"
nucleus.application {
    nativeDistributions {
        trustedCertificates.from(
            files(
                "certs/company-ca.pem",
                "certs/vpn-root.crt",
            ),
        )
    }
}
```

Le plugin accepte les fichiers PEM et DER, et l'empaquetage les importe pour vous. Seul le runtime
livré change : le système de l'utilisateur, son JDK et celui du build restent intacts.

`trustedCertificates` couvre les autorités connues au moment du build. Pour faire aussi confiance
aux autorités installées par l'utilisateur dans le magasin de l'OS, ajoutez
[`native-ssl`](/docs/performance/native-ssl).

## Référence de l'API

| Symbole | Type | Description |
| --- | --- | --- |
| `nativeDistributions.trustedCertificates` | `ConfigurableFileCollection` | Fichiers PEM ou DER à importer dans le `cacerts` du runtime livré. |
| `patchCaCertificates` | Tâche Gradle | Importe les certificats dans une copie de l'image runtime. N'existe que si `trustedCertificates` n'est pas vide. |
