---
title: Boutons de la souris
description: Gérez les boutons latéraux précédent et suivant d'une souris comme des boutons de pointeur Compose.
---

Les boutons latéraux d'une souris arrivent dans Compose sous la forme `PointerButton.Back` et
`PointerButton.Forward`, sous macOS, Windows et Linux. Utilisez-les pour naviguer dans un
historique, comme un navigateur ou un gestionnaire de fichiers :

```kotlin
Modifier.pointerInput(Unit) {
    awaitPointerEventScope {
        while (true) {
            val event = awaitPointerEvent()
            if (event.type != PointerEventType.Press) continue
            when (event.button) {
                PointerButton.Back -> navigator.back()
                PointerButton.Forward -> navigator.forward()
                else -> Unit
            }
        }
    }
}
```

Les fenêtres popup natives et l'overlay `NativeView` sous Windows ne reçoivent pas les boutons
latéraux.
