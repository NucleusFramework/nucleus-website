title: Icônes de pointeur
description: Affichez des curseurs de préhension, de déplacement, d'attente, d'aide et de redimensionnement avec TaoPointerIcons et Modifier.pointerHoverIcon.
---

import { Callout } from 'fumadocs-ui/components/callout';

`TaoPointerIcons` (`dev.nucleusframework.window.tao`, fourni avec `nucleus-application`) ajoute
les curseurs que Compose ne définit pas dans le code commun. Passez-les à
`Modifier.pointerHoverIcon` :

```kotlin
Modifier.pointerHoverIcon(if (dragging) TaoPointerIcons.Grabbing else TaoPointerIcons.Grab)
```

Les `PointerIcon.Default`, `Text`, `Hand` et `Crosshair` de Compose continuent de fonctionner.

## Icônes disponibles

| Icône | Usage courant |
| --- | --- |
| `Grab` / `Grabbing` | Poignée de glisser au survol / pendant le glisser |
| `Move` | Élément qui va se déplacer |
| `NotAllowed` | Dépôt refusé |
| `Wait` | L'application ignore les entrées |
| `Progress` | Occupée, mais toujours interactive |
| `Help` | Aide contextuelle |
| `ResizeEastWest` / `ResizeNorthSouth` | Séparateurs et bords de fenêtre |

Chaque icône utilise la forme propre de la plateforme, ou la flèche si la plateforme n'en a pas.

## Remplacer les curseurs AWT

<Callout type="warn" title="Modifié en 3.0">
`PointerIcon(Cursor(...))` n'associe que les types AWT prédéfinis texte, main, croix, attente,
déplacement et redimensionnement. Les autres curseurs AWT, y compris les images de
`Toolkit.createCustomCursor`, affichent la flèche.
</Callout>

| 2.x avec AWT | 3.0 |
| --- | --- |
| `PointerIcon(Cursor(Cursor.MOVE_CURSOR))` | `TaoPointerIcons.Move` |
| `PointerIcon(Cursor(Cursor.WAIT_CURSOR))` | `TaoPointerIcons.Wait` |
| `PointerIcon(Cursor(Cursor.E_RESIZE_CURSOR))` | `TaoPointerIcons.ResizeEastWest` |
| `PointerIcon(Cursor(Cursor.N_RESIZE_CURSOR))` | `TaoPointerIcons.ResizeNorthSouth` |
