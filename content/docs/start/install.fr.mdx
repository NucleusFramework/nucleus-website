Dans ce tutoriel, vous allez appliquer le plugin Gradle Nucleus à un projet Kotlin : un seul build
compile, lance et empaquette alors une application desktop pour macOS, Linux et Windows.

## Avant de commencer

- **JDK 17 ou plus récent** dans votre `PATH`, de n'importe quel éditeur. Le cache AOT et le toolkit Jewel exigent JDK 25.
- **Kotlin 2.4.20 ou plus récent** et **Gradle 9.0 ou plus récent**.

## Compatibilité

| Version de Nucleus | Version de Kotlin | Version de Compose |
|--------------------|-------------------|--------------------|
| 3.0.x              | 2.4.20+           | 1.12.1             |
| 2.5.0 – 2.5.18     | 2.4.10+           | 1.12.0             |
| 2.0.0 – 2.4.7      | 2.4.0+            | 1.11.1             |

Fixez le plugin Compose à la version exacte de votre ligne : 3.0.x ne tourne pas sur Compose 1.11.x.
La version de Kotlin est un minimum.

## Appliquer le plugin

Appliquez le plugin depuis le Gradle Plugin Portal, et utilisez la même `<version>` pour chaque
module runtime `dev.nucleusframework` publié sur Maven Central :

```kotlin title="build.gradle.kts"
plugins {
    kotlin("jvm") version "2.4.20"
    kotlin("plugin.compose") version "2.4.20"
    id("org.jetbrains.compose") version "1.12.1"
    id("dev.nucleusframework") version "<version>"
}

repositories {
    mavenCentral()
    google()
}

kotlin {
    jvmToolchain(25)
}
```

La toolchain compile votre code. Le JDK qui empaquette et lance l'application vient de `javaHome`,
ou de [`lastJdk`](/docs/performance/startup#empaqueter-avec-le-dernier-jdk).

## Vérifier le plugin

```shell
./gradlew tasks --group nucleus
```

Si Gradle liste les tâches `nucleus`, le plugin est appliqué.
