In this tutorial, you'll create a Nucleus desktop app from two files, run it in a native window,
and package it as an installer for your operating system. You need JDK 17+, Kotlin 2.4.10+ and
Gradle 9.0+ (see [Install](/docs/start/install#compatibility)).

## Create the build script

In an empty directory, create `build.gradle.kts`:

```kotlin title="build.gradle.kts"
import dev.nucleusframework.desktop.application.dsl.TargetFormat

plugins {
    kotlin("jvm") version "2.4.10"
    kotlin("plugin.compose") version "2.4.10"
    id("org.jetbrains.compose") version "1.12.0"
    id("dev.nucleusframework") version "<version>"
}

repositories {
    mavenCentral()
    google()
}

dependencies {
    implementation(compose.desktop.currentOs)
    implementation("dev.nucleusframework:nucleus.nucleus-application:<version>")
}

nucleus.application {
    mainClass = "com.example.MainKt"

    nativeDistributions {
        packageName = "MyApp"
        packageVersion = "1.0.0"
        targetFormats(TargetFormat.Dmg, TargetFormat.Msi, TargetFormat.Deb)
    }
}
```

`nucleus-application` is the only Nucleus dependency the app needs. Coming from Compose Desktop?
See [Migrate from JetBrains Compose Desktop](/docs/migrate/from-jb-compose).

## Write the application

Create `src/main/kotlin/com/example/Main.kt`:

```kotlin title="Main.kt"
package com.example

import androidx.compose.material.Text
import dev.nucleusframework.application.DecoratedWindow
import dev.nucleusframework.application.nucleusApplication

fun main(args: Array<String>) = nucleusApplication(args) {
    DecoratedWindow(onCloseRequest = ::exitApplication, title = "MyApp") {
        Text("Hello from Nucleus")
    }
}
```

`DecoratedWindow` opens a Compose window with a native title bar. Pass the process `args` so deep
links and file associations reach the app.

<Callout type="warn" title="Changed in 3.0">
`nucleusApplication` has no `backend` parameter, and Compose Desktop's `Window`, `Dialog`, and
`Tray` do not work inside it. See [Migrate from Nucleus 2.x](/docs/migrate/from-2.x).
</Callout>

## Run the app

```shell
./gradlew run
```

For Compose Hot Reload, apply `org.jetbrains.compose.hot-reload` and run `./gradlew hotRun`. On
macOS, also declare `dev.nucleusframework:nucleus.decorated-window-tao:<version>` in the module, or
the hot reload window does not open.

## Package the app

```shell
./gradlew packageDistributionForCurrentOS
```

The installer lands in `build/compose/binaries/main/<format>/`. See
[Configuration](/docs/start/configuration#select-packaging-formats) to add formats.
