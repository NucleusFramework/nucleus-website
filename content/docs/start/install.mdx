In this tutorial, you'll apply the Nucleus Gradle plugin to a Kotlin project, so one build
compiles, runs, and packages a desktop app for macOS, Linux, and Windows.

## Before you start

- **JDK 17 or later** on your `PATH`, from any vendor. The AOT cache and the Jewel toolkit need JDK 25.
- **Kotlin 2.4.20 or later** and **Gradle 9.0 or later**.

## Compatibility

| Nucleus version | Kotlin version | Compose version |
|-----------------|----------------|-----------------|
| 3.0.x           | 2.4.20+        | 1.12.1          |
| 2.5.0 – 2.5.18  | 2.4.10+        | 1.12.0          |
| 2.0.0 – 2.4.7   | 2.4.0+         | 1.11.1          |

Pin the Compose plugin to the exact version of your row: 3.0.x does not run on Compose 1.11.x. The
Kotlin version is a minimum.

## Apply the plugin

Apply the plugin from the Gradle Plugin Portal, and use the same `<version>` for every
`dev.nucleusframework` runtime module on Maven Central:

```kotlin title="build.gradle.kts"
plugins {
    kotlin("jvm") version "2.4.20"
    kotlin("plugin.compose") version "2.4.20"
    id("org.jetbrains.compose") version "1.12.1"
    id("dev.nucleusframework") version "<version>"
}

repositories {
    mavenCentral()
    google()
}

kotlin {
    jvmToolchain(25)
}
```

The toolchain compiles your code. The JDK that packages and runs the app comes from `javaHome`, or
from [`lastJdk`](/docs/performance/startup#package-with-the-latest-jdk).

## Verify the plugin

```shell
./gradlew tasks --group nucleus
```

If Gradle lists the `nucleus` tasks, the plugin is applied.
