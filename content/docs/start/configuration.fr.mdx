Le bloc `nucleus.application { }` de `build.gradle.kts` indique au plugin comment lancer et
empaqueter votre application. Une application Kotlin/Native utilise `nucleus.nativeApplication { }`,
voir [la référence du DSL Gradle](/docs/reference/gradle-dsl#native-application).

## Écrire la configuration minimale

```kotlin title="build.gradle.kts"
import dev.nucleusframework.desktop.application.dsl.TargetFormat

nucleus.application {
    mainClass = "com.example.MainKt" // fun main in com/example/Main.kt

    nativeDistributions {
        packageName = "MyApp"
        packageVersion = "1.0.0"
        description = "Notes that sync across devices"
        vendor = "Example Corp"
        homepage = "https://myapp.example.com" // required for DEB and RPM
        targetFormats(TargetFormat.Dmg, TargetFormat.Msi, TargetFormat.Deb)

        macOS {
            bundleID = "com.example.myapp"
            iconFile.set(project.file("icons/app.icns"))
        }
        windows { iconFile.set(project.file("icons/app.ico")) }
        linux { iconFile.set(project.file("icons/app.png")) }
    }
}
```

`packageName` et `packageVersion` se retrouvent dans le nom des installateurs et les métadonnées de
l'OS.

## Sélectionner les formats de packaging

`targetFormats(...)` accepte n'importe laquelle des 18 valeurs de `TargetFormat`. Chaque machine de
build produit les formats de son propre OS.

| OS | Formats |
|---|---|
| macOS | `Dmg`, `Pkg` |
| Windows | `Msi`, `Exe`, `Nsis`, `NsisWeb`, `Portable`, `AppX` |
| Linux | `Deb`, `Rpm`, `AppImage`, `Pacman`, `Snap`, `Flatpak` |
| Tous | `Zip`, `Tar`, `SevenZ`, `RawAppImage` |
