Dans ce tutoriel, vous allez créer une application desktop Nucleus en deux fichiers, la lancer dans
une fenêtre native et l'empaqueter en installateur pour votre système. Il vous faut JDK 17+,
Kotlin 2.4.10+ et Gradle 9.0+ (voir [Installation](/docs/start/install#compatibilité)).

## Créer le script de build

Dans un répertoire vide, créez `build.gradle.kts` :

```kotlin title="build.gradle.kts"
import dev.nucleusframework.desktop.application.dsl.TargetFormat

plugins {
    kotlin("jvm") version "2.4.10"
    kotlin("plugin.compose") version "2.4.10"
    id("org.jetbrains.compose") version "1.12.0"
    id("dev.nucleusframework") version "<version>"
}

repositories {
    mavenCentral()
    google()
}

dependencies {
    implementation(compose.desktop.currentOs)
    implementation("dev.nucleusframework:nucleus.nucleus-application:<version>")
}

nucleus.application {
    mainClass = "com.example.MainKt"

    nativeDistributions {
        packageName = "MyApp"
        packageVersion = "1.0.0"
        targetFormats(TargetFormat.Dmg, TargetFormat.Msi, TargetFormat.Deb)
    }
}
```

`nucleus-application` est la seule dépendance Nucleus dont l'application a besoin. Vous venez de
Compose Desktop ? Voir [Migrer depuis JetBrains Compose Desktop](/docs/migrate/from-jb-compose).

## Écrire l'application

Créez `src/main/kotlin/com/example/Main.kt` :

```kotlin title="Main.kt"
package com.example

import androidx.compose.material.Text
import dev.nucleusframework.application.DecoratedWindow
import dev.nucleusframework.application.nucleusApplication

fun main(args: Array<String>) = nucleusApplication(args) {
    DecoratedWindow(onCloseRequest = ::exitApplication, title = "MyApp") {
        Text("Hello from Nucleus")
    }
}
```

`DecoratedWindow` ouvre une fenêtre Compose avec une barre de titre native. Transmettez les `args`
du processus pour que les deep links et les associations de fichiers parviennent à l'application.

<Callout type="warn" title="Modifié en 3.0">
`nucleusApplication` n'a plus de paramètre `backend`, et les `Window`, `Dialog` et `Tray` de
Compose Desktop n'y fonctionnent pas. Voir [Migrer depuis Nucleus 2.x](/docs/migrate/from-2.x).
</Callout>

## Lancer l'application

```shell
./gradlew run
```

Pour Compose Hot Reload, appliquez `org.jetbrains.compose.hot-reload` et lancez `./gradlew hotRun`.
Sous macOS, déclarez aussi `dev.nucleusframework:nucleus.decorated-window-tao:<version>` dans le
module, sans quoi la fenêtre du hot reload ne s'ouvre pas.

## Empaqueter l'application

```shell
./gradlew packageDistributionForCurrentOS
```

L'installateur arrive dans `build/compose/binaries/main/<format>/`. Voir
[Configuration](/docs/start/configuration#sélectionner-les-formats-de-packaging) pour ajouter des
formats.
