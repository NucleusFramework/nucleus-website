Nucleus est la couche desktop des applications Compose Multiplatform écrites en Kotlin. Compose dessine
l'interface. Nucleus ouvre les fenêtres natives, dialogue avec le système d'exploitation et produit des
installateurs signés, le tout depuis un seul DSL Gradle. Votre application tourne comme image native
GraalVM ou sur la JVM.

Pour construire votre première application, suivez le [démarrage rapide](/docs/start/quickstart).

<Callout title="Une application existante à migrer ? Confiez-la à un agent IA">
Collez un seul prompt dans votre agent de code : il migre votre application phase par phase. Voir
[Migrer avec un agent IA](/docs/migrate/ai-agent).
</Callout>

## Fonctionnalités

- **Des fenêtres natives sans AWT**, avec Wayland, les gestes du trackpad, le stylet,
  les [vues natives](/docs/native-content/native-views) et les [textures GPU](/docs/native-content/texture-view).
- **[Multifenêtre](/docs/multi-window)** : palettes ancrables et onglets façon Chrome à détacher et fusionner.
- **Deux runtimes, un DSL** : une image native GraalVM, ou la JVM avec un cache AOT (JDK 25+).
- **Plus de 30 modules runtime** : notifications, tray, menus du Dock, mode sombre, raccourcis globaux, correcteur orthographique, etc.
- **18 formats de packaging**, avec signature, notarisation et [mise à jour différentielle](/docs/packaging/auto-update#téléchargements-différentiels).
- **Design systems natifs** : macOS 26, Fluent, Yaru, Jewel et Material. Voir [Toolkits](/docs/toolkits).
- **Un seul langage sur toutes les plateformes** : partagez le code Kotlin et l'UI Compose avec vos applications Android, iOS et web.
  Passer de Compose Desktop revient à remplacer `compose.desktop.application` par `nucleus.application`.
  Voir [Nucleus et Compose Multiplatform seul](/docs/compare/cmp-default).

## Quoi de neuf en 3.0

Nucleus 3.0 casse la compatibilité source et binaire avec 2.x. Lisez le
[guide de migration](/docs/migrate/from-2.x) avant de mettre à jour.

- **Un seul backend de fenêtres.** Les backends AWT, JBR et JNI et l'argument `backend =` disparaissent.
- **Plus de fenêtres Compose Desktop.** Ouvrez vos fenêtres avec `DecoratedWindow` ou `HostedWindow` au
  lieu de `Window`, `Dialog` et `Tray`.
- **Callbacks sur le thread UI**, et sous macOS Cmd+Q passe par le `onCloseRequest` de chaque fenêtre.
- **API d'état de fenêtre v2** sans AWT, dans `dev.nucleusframework.window.tao.v2`.
- **Satellites, dock et onglets**, en API [multifenêtre](/docs/multi-window) expérimentale.
- **Le packaging** télécharge son propre Node.js et ajoute `nucleusOptimization` et un PKG Developer ID.

Liste complète : [Changelog](/docs/changelog).
