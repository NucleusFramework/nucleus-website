Nucleus est un framework Kotlin pour créer des applications de bureau natives multiplateformes. Il s'appuie sur Compose Multiplatform et ajoute les décorations de fenêtre natives, l'intégration au système d'exploitation, la signature de code et les installateurs natifs. Vous configurez tout le build via un seul DSL Gradle, et le runtime s'exécute soit comme une image native GraalVM, soit sur la JVM.

## Fonctionnalités

- **Un seul langage pour toutes les plateformes.** Partagez votre code Kotlin avec vos apps Android, iOS et web, avec Compose UI par-dessus.
- **Backend Tao.** Fenêtrage natif en Rust avec Wayland, multi-touch, stylet, et les API de chrome du [scaffold de fenêtre](/docs/tao/window-scaffold).
- **Deux runtimes, un seul DSL.** Exécution en image native GraalVM, ou sur la JVM avec un cache AOT (JDK 25+).
- **Plus de 40 modules d'intégration OS.** Notifications, system tray, menus dock, dark mode, hotkeys globaux et barre des tâches, chacun ajouté comme dépendance optionnelle.
- **18 formats d'installateur.** DMG, PKG, MSI, AppX, DEB, RPM, AppImage, Snap et Flatpak entre autres, avec signature de code et notarisation.
- **Design systems natifs.** [macOS 26](https://github.com/NucleusFramework/compose-macos-26-ui), [Fluent](https://github.com/NucleusFramework/compose-fluent-ui) et [Yaru](https://github.com/NucleusFramework/yaru-compose-ui) sur Maven Central, plus Jewel et Material dans ce dépôt. Voir [toolkits](/docs/window/toolkits).

Pour construire votre première app, suivez le [quickstart](/docs/start/quickstart).

## Quoi de neuf en 2.2

- **Scaffold de fenêtre et chrome.** Mises en page plein fenêtre, zones de drag, `WindowControls`, régions de verre macOS, Mica/Acrylic Windows. Voir [Scaffold de fenêtre](/docs/tao/window-scaffold).
- **Parité des tâches GraalVM.** `runGraalvmNative` en quick-build, tâches distributable alignées sur le pipeline JVM, [sélection du GC](/docs/performance/graalvm/configuration#choisir-un-garbage-collector).
- **AccessKit sous Windows** et [deep links](/docs/lifecycle/deep-links#fonctionnement) scheme-only.
- **Sorties design system.** Bibliothèques Fluent, macOS 26 et Yaru Compose UI avec fenêtres décorées basées sur Nucleus.
