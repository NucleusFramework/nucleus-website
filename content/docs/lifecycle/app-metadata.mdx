`NucleusApp` reads your app's id, version, vendor, display name, and Windows AUMID from Kotlin.
The Gradle plugin injects the values you configure, so you never hardcode them. `NucleusApp`
ships in `core-runtime`, which comes with `nucleus-application`.

## Read the metadata

```kotlin
@Composable
fun AboutDialog() {
    Column {
        Text(NucleusApp.appName ?: NucleusApp.appId)
        NucleusApp.version?.let { Text("Version $it") }
        NucleusApp.vendor?.let { Text("by $it") }
    }
}
```

`appId` and `aumid` are never null. Guard the other properties or supply a fallback.
`isConfigured` tells you whether the plugin injected metadata at all.

<Callout type="info">
`isConfigured` is also `true` under `./gradlew run`. To keep auto-update or telemetry out of
development runs, test `ExecutableRuntime.isDev()`. See
[Executable type](/docs/lifecycle/executable-type).
</Callout>

<Accordions>
<Accordion title="Under the hood">

- Each property takes the first non-blank value from the `nucleus.app.*` system properties, then
  the `nucleus/nucleus-app.properties` resource in packaged JARs. It resolves once and is cached.
- The `run` task gets only `-Dnucleus.app.id` and `-Dnucleus.executable.type`.
- `isConfigured` checks only `nucleus.app.id` and the resource file, not each property.
- The same values name the single-instance lock, the Windows AUMID used by toasts, badges, and
  jump lists, the MSIX startup task, and the FileKit data directory.

</Accordion>
</Accordions>

## API reference

| Property | Type | Value |
|---|---|---|
| `appId` | `String` | Matches the plugin's `packageName`. Falls back to a value derived from the main class. |
| `appName` | `String?` | Display name. |
| `version` | `String?` | Application version. |
| `vendor` | `String?` | Application vendor. |
| `description` | `String?` | Application description. |
| `aumid` | `String` | Windows Application User Model ID. Falls back to `appId`. |
| `startupTaskId` | `String?` | MSIX startup task id, set when `appx { addAutoLaunchExtension = true }`. Read by [Auto-launch](/docs/lifecycle/background/launch-at-login). |
| `isConfigured` | `Boolean` | `true` when the plugin injected metadata. |
