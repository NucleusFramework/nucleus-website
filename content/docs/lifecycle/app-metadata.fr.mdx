`NucleusApp` lit l'id, la version, le vendeur, le nom d'affichage et l'AUMID Windows de votre app
depuis Kotlin. Le plugin Gradle injecte les valeurs que vous configurez : vous ne les codez
jamais en dur. `NucleusApp` est fourni par `core-runtime`, qu'apporte `nucleus-application`.

## Lire les métadonnées

```kotlin
@Composable
fun AboutDialog() {
    Column {
        Text(NucleusApp.appName ?: NucleusApp.appId)
        NucleusApp.version?.let { Text("Version $it") }
        NucleusApp.vendor?.let { Text("par $it") }
    }
}
```

`appId` et `aumid` ne sont jamais nuls. Protégez les autres propriétés ou fournissez une valeur
de repli. `isConfigured` indique si le plugin a injecté des métadonnées.

<Callout type="info">
`isConfigured` vaut aussi `true` sous `./gradlew run`. Pour exclure la mise à jour automatique
ou la télémétrie des lancements de dev, testez `ExecutableRuntime.isDev()`. Voir
[Type d'exécutable](/docs/lifecycle/executable-type).
</Callout>

<Accordions>
<Accordion title="En coulisses">

- Chaque propriété prend la première valeur non vide parmi les propriétés système
  `nucleus.app.*`, puis la ressource `nucleus/nucleus-app.properties` des JAR empaquetés. Elle
  est résolue une fois puis mise en cache.
- La tâche `run` ne reçoit que `-Dnucleus.app.id` et `-Dnucleus.executable.type`.
- `isConfigured` ne vérifie que `nucleus.app.id` et le fichier de ressource, pas chaque propriété.
- Les mêmes valeurs nomment le verrou d'instance unique, l'AUMID Windows des toasts, badges et
  jump lists, la tâche de démarrage MSIX et le dossier de données FileKit.

</Accordion>
</Accordions>

## Référence de l'API

| Propriété | Type | Valeur |
|---|---|---|
| `appId` | `String` | Correspond au `packageName` du plugin. Repli : une valeur dérivée de la classe principale. |
| `appName` | `String?` | Nom d'affichage. |
| `version` | `String?` | Version de l'application. |
| `vendor` | `String?` | Vendeur de l'application. |
| `description` | `String?` | Description de l'application. |
| `aumid` | `String` | Application User Model ID Windows. Repli : `appId`. |
| `startupTaskId` | `String?` | Id de la tâche de démarrage MSIX, défini quand `appx { addAutoLaunchExtension = true }`. Lu par [Démarrage au login](/docs/lifecycle/background/launch-at-login). |
| `isConfigured` | `Boolean` | `true` quand le plugin a injecté des métadonnées. |

## Et ensuite

- [Type d'exécutable](/docs/lifecycle/executable-type) : distinguer un DMG, un Flatpak ou `./gradlew run`.
- [Instance unique](/docs/lifecycle/single-instance) : le verrou qui porte le nom de votre id d'app.
- [Démarrage au login](/docs/lifecycle/background/launch-at-login) : démarrer l'app au login avec `startupTaskId`.
