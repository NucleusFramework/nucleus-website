title: Cycle de vie
description: Les modules qui relient une app Nucleus aux événements et services de l'OS qui dépassent une seule fenêtre.

Les modules de cycle de vie relient votre app aux événements et services de l'OS qui dépassent
n'importe quelle fenêtre. `nucleus-application` apporte `core-runtime` ; ajoutez les autres
modules selon vos besoins. Chacun reste sans effet sur les plateformes qu'il ne gère pas : vous
pouvez l'appeler depuis du code commun.

| Étape | Module | Page |
|---|---|---|
| Démarrage, sortie et quit système | `nucleus-application` | [Point d'entrée de l'application](/docs/lifecycle/application) |
| Verrou d'instance | `core-runtime` | [Instance unique](/docs/lifecycle/single-instance) |
| Schémas d'URL | `core-runtime` + DSL du plugin | [Deep links](/docs/lifecycle/deep-links) |
| Id, version et vendeur de l'app à l'exécution | `core-runtime` | [Métadonnées de l'app](/docs/lifecycle/app-metadata) |
| Format de packaging et sandbox | `core-runtime` | [Type d'exécutable](/docs/lifecycle/executable-type) |
| Menu du Dock (macOS) | `launcher-macos` | [macOS Dock menu](/docs/os/dock-taskbar/macos) |
| Icônes de superposition, jump lists, badges (Windows) | `launcher-windows` | [Windows taskbar](/docs/os/dock-taskbar/windows) |
| Badges et quicklists du launcher (Linux) | `launcher-linux` | [Linux launcher](/docs/os/dock-taskbar/linux) |
| Démarrage au login | `autolaunch` | [Démarrage au login](/docs/lifecycle/background/launch-at-login) |
| Travail de fond périodique et calendaire | `scheduler`, `scheduler-testing` | [Scheduler](/docs/lifecycle/background/scheduler) |
| Agents `SMAppService` (macOS) | `service-management-macos` | [Service management](/docs/lifecycle/background/service-management) |
| Mode efficacité et maintien en éveil | `energy-manager` | [Energy manager](/docs/lifecycle/energy-manager) |
| Progression sur le Dock ou la barre des tâches | `taskbar-progress`, `taskbar-progress-tao` | [Taskbar progress](/docs/os/dock-taskbar/progress) |
| Changements de fichiers et de dossiers | `fs-watcher` | [Filesystem watcher](/docs/lifecycle/fs-watcher) |
