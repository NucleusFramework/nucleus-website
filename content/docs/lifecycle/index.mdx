---
title: Lifecycle
description: The modules that connect a Nucleus app to OS events and services that outlive a single window.
---

The lifecycle modules connect your app to OS events and services that outlive any window.
`nucleus-application` brings `core-runtime`; add the other modules when you need them. Each one
does nothing on platforms it does not support, so you can call it from common code.

| Stage | Module | Page |
|---|---|---|
| Startup, exit, and system quit | `nucleus-application` | [Application entry point](/docs/lifecycle/application) |
| Instance locking | `core-runtime` | [Single instance](/docs/lifecycle/single-instance) |
| URL schemes | `core-runtime` + plugin DSL | [Deep links](/docs/lifecycle/deep-links) |
| App id, version, and vendor at runtime | `core-runtime` | [App metadata](/docs/lifecycle/app-metadata) |
| Packaging format and sandbox | `core-runtime` | [Executable type](/docs/lifecycle/executable-type) |
| Dock menu (macOS) | `launcher-macos` | [macOS Dock menu](/docs/os/dock-taskbar/macos) |
| Overlay icons, jump lists, badges (Windows) | `launcher-windows` | [Windows taskbar](/docs/os/dock-taskbar/windows) |
| Launcher badges and quicklists (Linux) | `launcher-linux` | [Linux launcher](/docs/os/dock-taskbar/linux) |
| Launch at login | `autolaunch` | [Auto-launch](/docs/lifecycle/background/launch-at-login) |
| Periodic and calendar background work | `scheduler`, `scheduler-testing` | [Scheduler](/docs/lifecycle/background/scheduler) |
| `SMAppService` agents (macOS) | `service-management-macos` | [Service management](/docs/lifecycle/background/service-management) |
| Efficiency mode and keep-awake | `energy-manager` | [Energy manager](/docs/lifecycle/energy-manager) |
| Progress on the Dock or taskbar | `taskbar-progress`, `taskbar-progress-tao` | [Taskbar progress](/docs/os/dock-taskbar/progress) |
| File and directory changes | `fs-watcher` | [Filesystem watcher](/docs/lifecycle/fs-watcher) |
